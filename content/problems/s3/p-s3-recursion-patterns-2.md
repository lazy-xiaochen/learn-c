## 题目描述
小周写了一个递归函数来计算"连乘"：

```c
int g(int i, int n) {
    if (i == n) {
        return a[n];              /* 最后一层：直接返回 a[n] */
    }
    return a[i] * g(i + 1, n);    /* 其余各层：a[i] 乘上"后面所有数的乘积" */
}
```

其中 `a[1..n]` 是输入的整数。这个函数本身写得没错，问题在于 `a[i]` 和返回值都是 `int`。**乘法是在"回归"阶段一层层做的**：先算出 `g(n) = a[n]`，然后算出 `g(n-1) = a[n-1] * g(n)`，再算 `g(n-2)`……一直到 `g(1)`。

请写一个"溢出巡检器"：按这个顺序推演每一步的乘法，找出**第一次**发生有符号整数溢出的层号，并给出这一层本该得到的真实乘积。

规则：

1. 第 `n` 层是 `g(n) = a[n]`，直接取值（`|a[i]| ≤ 10`，不可能越界）；
2. 从第 `n-1` 层开始，按 `n-1, n-2, …, 1` 的顺序，每一层计算 `a[i] * g(i+1)`；
3. 如果这一步的结果落在 `int` 的表示范围内（`-2147483648 ≤ 值 ≤ 2147483647`），继续往下一层；
4. 如果超出范围，说明这一层的 `int` 乘法是**有符号整数溢出**——在 C 里这是未定义行为（UB），不是"回绕"：程序可能崩溃、可能得到负数、也可能被编译器优化掉。巡检到此结束；
5. 如果一路到第 1 层都没有溢出，就输出最终结果。

注意第 3 条的两个端点：`-2147483648`（`INT_MIN`）本身是**合法**的，能存进 `int`；只有超出它才算溢出。反过来，`INT_MIN` 再乘 `-1` 得到 `+2147483648`，就溢出了。

## 输入格式
第一行一个整数 `n`（1 ≤ n ≤ 2000）。

第二行 `n` 个整数 `a[1] … a[n]`，用空格分隔。

## 输出格式
只输出一行：

- 如果第 `i` 层发生了溢出：`UB i v`，其中 `i` 是层号（从 1 开始），`v` 是这一层**数学上正确**的乘积（可能超出 `int`，用 64 位整数输出）；
- 如果一路没有溢出：`OK v`，其中 `v` 是 `g(1)` 的值。

## 数据范围
- `1 ≤ n ≤ 2000`；
- `-10 ≤ a[i] ≤ 10`，可能为 0、1、-1；
- 溢出发生前，每一层的乘积都在 `int` 范围内；溢出那一层的真实值最大约 `2.2×10¹⁰`，`long long` 装得下；
- 没有溢出时，最终结果也在 `int` 范围内。

## 示例
### 示例 1
```in
4
2 3 4 5
```
```out
OK 120
```
> 从第 4 层往回算：`g(4) = 5`，`g(3) = 4×5 = 20`，`g(2) = 3×20 = 60`，`g(1) = 2×60 = 120`。全程在 `int` 范围内，输出 `OK 120`。

### 示例 2（边界：只有一层）
```in
1
7
```
```out
OK 7
```
> `n = 1` 时没有乘法，`g(1) = a[1] = 7`。

## 提示
### 第 1 层
不要从 `a[1]` 往 `a[n]` 乘——递归的**计算顺序正好相反**：先有 `g(n) = a[n]`，再从 `n-1` 递减到 1 逐层相乘。顺序错了，第一次溢出的层号就会完全不同。

### 第 2 层
用一个 `long long` 变量 `v` 保存"当前这一层算出来的乘积"，从 `v = a[n]` 开始。每一层先算 `p = v * a[i]`（`long long` 乘法不会溢出，因为量级最多 2×10¹⁰），再和 `INT_MAX`、`INT_MIN` 比较：

```c
if (p > INT_MAX || p < INT_MIN) { /* 第 i 层溢出 */ }
```

**两个边界都要判断**：只写 `p > INT_MAX` 会漏掉负数方向的溢出。

### 第 3 层
`INT_MAX` / `INT_MIN` 来自 `<limits.h>`。层号是 `i`（1 到 `n`），循环变量如果用 0 起的下标，记得输出时 `+1`。溢出时直接 `printf("UB %d %lld\n", i, p)` 然后 `return 0`，不要继续往下乘。

## 参考代码
```c file=main.c
#include <stdio.h>
#include <limits.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 2000) {
        return 0;
    }

    int a[2000];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1 || a[i] < -10 || a[i] > 10) {
            return 0;
        }
    }

    long long v = a[n - 1];              /* g(n)：最内层，直接取值 */
    for (int i = n - 2; i >= 0; i--) {   /* 从 n-1 层往回乘到第 1 层 */
        long long p = v * a[i];
        if (p > INT_MAX || p < INT_MIN) {
            printf("UB %d %lld\n", i + 1, p);
            return 0;
        }
        v = p;
    }
    printf("OK %lld\n", v);
    return 0;
}
```

## 复杂度
时间 O(n)：从第 `n` 层往回扫一遍，每层一次乘法和两次比较。
空间 O(n)：保存输入的数组（也可以边读边记录最后一个数，把空间降到 O(1)，但没必要）。

## 常见错误
### 用 int 相乘再判断是否溢出 [UB]
"先乘出来再检查"在 `int` 上根本不成立：乘法**本身**已经溢出了，这一步就是未定义行为，本平台的 UBSan 会当场报 `signed integer overflow`。检测溢出必须在更宽的类型（`long long`）里做，或者在乘法**之前**用除法判断。
```c file=main.c expect=UB
#include <stdio.h>
#include <limits.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 2000) {
        return 0;
    }
    int a[2000];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }

    int v = a[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        int p = v * a[i];                /* 错：这里已经溢出了，UB 先发生 */
        if (p > INT_MAX || p < INT_MIN) {
            printf("UB %d %d\n", i + 1, p);
            return 0;
        }
        v = p;
    }
    printf("OK %d\n", v);
    return 0;
}
```

### 只检查正溢出，漏掉负数方向 [WA]
`p > INT_MAX` 只能抓住正溢出。输入 `-3 10 10 …` 时乘积会掉到 `-3×10⁹`，比 `INT_MIN` 还小，但程序会当作正常，最后输出 `OK -3000000000`，而正确答案是 `UB 1 -3000000000`。
```c file=main.c expect=WA
#include <stdio.h>
#include <limits.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 2000) {
        return 0;
    }
    int a[2000];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }

    long long v = a[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        long long p = v * a[i];
        if (p > INT_MAX) {              /* 错：漏掉了 p < INT_MIN */
            printf("UB %d %lld\n", i + 1, p);
            return 0;
        }
        v = p;
    }
    printf("OK %lld\n", v);
    return 0;
}
```

### 层号用 0 起的下标输出 [WA]
数组下标是 0 起，但题目要求输出的是"第几层"，从 1 开始。`printf("UB %d …", i)` 会比正确答案小 1，例如 `12 个 10` 的用例应该输出 `UB 3 10000000000`，却输出了 `UB 2 …`。
```c file=main.c expect=WA
#include <stdio.h>
#include <limits.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 2000) {
        return 0;
    }
    int a[2000];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }

    long long v = a[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        long long p = v * a[i];
        if (p > INT_MAX || p < INT_MIN) {
            printf("UB %d %lld\n", i, p);   /* 错：层号应该是 i + 1 */
            return 0;
        }
        v = p;
    }
    printf("OK %lld\n", v);
    return 0;
}
```

### 把回绕后的 int 值当成"真实值"输出 [WA]
溢出的那一刻，`int` 里剩下什么是未定义的；即使按"二进制回绕"去猜，得到的也是 `-2147483648` 这类负数，而不是数学上正确的 `2147483648`。题目要求输出的是**真实乘积**，必须在 `long long` 里算。

### 从 a[1] 开始往 a[n] 乘 [WA]
递归的乘法顺序是"由内向外"，也就是下标从 `n` 递减到 `1`。从 `a[1]` 顺着乘虽然最终结果一样（乘法满足交换律），但**第一次溢出的层号会完全不同**，输出必然错。
