## 题目描述
教研组想看看一次考试的分数"散得有多开"。除了平均分，他们还要两个指标：

- **偏差平方和** `ssq = Σ (xᵢ − mean)²`——放大了大偏差的影响；
- **平均绝对偏差** `mad = Σ |xᵢ − mean|`——对每个偏差一视同仁。

其中 `mean` 是**整数的平均分**：`mean = 总分 / n`（整除，向下取整）。

工程里已经用两个**函数宏**把"平方"和"绝对值"封装起来了：

```c
#define SQR(x) ...
#define ABS(x) ...
```

起始代码里这两个宏"能编译、能跑"，但算出来的三个数字全不对。任务就是找出宏的问题并修好它——注意：**真正要考的不是数学，是宏展开**。`SQR(a[i] - mean)` 里的参数不是一个变量，而是一个表达式 `a[i] - mean`，宏在替换时会把它原样塞进宏体，优先级立刻发生变化。

要求：

1. `ssq` 和 `mad` 用 `long long` 保存并输出（最大约 10¹¹，`int` 装不下）；
2. 输出三行，格式见下；
3. **必须使用这两个宏**（`SQR` 和 `ABS` 各至少被调用一次），不要把它们换成手写表达式——这道题练的就是宏的写法。

## 输入格式
第一行一个整数 `n`：分数个数。
第二行 `n` 个整数，用空格分隔，依次是每个分数。

## 输出格式
三行：

```
mean=<平均分>
ssq=<偏差平方和>
mad=<平均绝对偏差>
```

## 数据范围
- `2 ≤ n ≤ 1000`；
- `0 ≤ 每个分数 ≤ 10000`；
- 总分最大 10⁷，`int` 装得下；但 `Σ (xᵢ − mean)²` 最大可达 `1000 × 10000² = 10¹¹`，**必须用 `long long`**；
- `mad` 最大 `1000 × 10000 = 10⁷`，也一并按 `long long` 输出。

## 示例
### 示例 1
```in
5
10 20 30 40 50
```
```out
mean=30
ssq=1000
mad=60
```
> 总分 150，`mean = 150 / 5 = 30`。偏差是 −20、−10、0、10、20：平方和 `400 + 100 + 0 + 100 + 400 = 1000`，绝对值和 `20 + 10 + 0 + 10 + 20 = 60`。

### 示例 2（边界：只有两个分数且相同）
```in
2
7 7
```
```out
mean=7
ssq=0
mad=0
```
> `n = 2` 是数据范围的下界，两个分数一样时所有偏差都是 0。这组数据能暴露"循环少跑一次"或"宏把 0 算错"的问题。

## 提示
### 第 1 层
分两遍扫：第一遍求和算出 `mean`（注意是**整型除法**，向下取整），第二遍再遍历一次，把每个 `a[i]` 和 `mean` 的偏差累加进 `ssq` 和 `mad`。两个指标都是"先算偏差、再处理偏差"，所以偏差最好只算一次。

### 第 2 层
看这两个宏的定义：

```c
#define SQR(x) x * x
#define ABS(x) x < 0 ? -x : x
```

调用处的实参是 `a[i] - mean`。把它原样代进去：`SQR(a[i] - mean)` 变成 `a[i] - mean * a[i] - mean`——乘法先算，这个式子的含义完全变了。`ABS(a[i] - mean)` 变成 `a[i] - mean < 0 ? -a[i] - mean : a[i] - mean`——`-x` 里的负号只作用到 `a[i]` 上，`mean` 根本没被取负。

修法是两条一起用：**每个参数出现的位置都加括号，整个宏体再加一层括号**，即 `((x) * (x))`、`((x) < 0 ? -(x) : (x))`。

### 第 3 层
改完宏之后还有三个细节：

1. `ssq` 用 `long long`（10¹¹），`int` 会溢出，溢出是未定义行为而不是"变成负数"；
2. `mean` 必须是整数：`long long sum` 求和之后 `(int)(sum / n)`，不要用 `double`；
3. 边界：`n = 2`、全部分数相同、全部是 0。这三种情况都不该让宏或循环出问题。

另外注意：宏参数会被**求值多次**，所以千万别在调用处写 `SQR(a[i++])` 这种带自增的实参。

## 参考代码
```c file=main.c
#include <stdio.h>

#define MAX_N 1000

/* 函数宏的两条铁律：每个参数加括号，整个宏体再加一层括号。
   SQR(a[i] - mean) 展开后是 ((a[i] - mean) * (a[i] - mean))，含义才和调用处一致。 */
#define SQR(x) ((x) * (x))
#define ABS(x) ((x) < 0 ? -(x) : (x))

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 2 || n > MAX_N) {
        return 0;
    }

    static int a[MAX_N];
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1 || a[i] < 0 || a[i] > 10000) {
            return 0;
        }
        sum += a[i];
    }

    int mean = (int)(sum / n);          /* 整型除法：向下取整 */

    long long ssq = 0;                  /* 最大约 10^11，必须 long long */
    long long mad = 0;
    for (int i = 0; i < n; i++) {
        ssq += SQR(a[i] - mean);        /* 宏里是 (x)*(x)，参数是一个表达式也没问题 */
        mad += ABS(a[i] - mean);
    }

    printf("mean=%d\n", mean);
    printf("ssq=%lld\n", ssq);
    printf("mad=%lld\n", mad);
    return 0;
}
```

## 复杂度
时间 O(n)：一遍求和，一遍算偏差。
空间 O(n)：一个 `int a[1000]`，约 4KB。

这段代码只把宏展开修好就能通过，算法本身没有难点。真正值得记住的是"**宏展开是按文本进行的**"：`SQR(a[i] - mean)` 里参数是"一个表达式"，而宏体里的 `x * x` 是最松散的写法，两者拼在一起就成了另一个式子。同样的道理，`ABS` 里 `-x` 只否定紧跟的那个操作数，不加括号时 `mean` 根本轮不到被取负。

## 常见错误
### 只给参数加了括号，或者一个括号都没加 [WA]
`#define SQR(x) x * x` 碰上实参 `a[i] - mean`，展开成 `a[i] - mean * a[i] - mean`，结果和平方毫无关系。`ABS` 更隐蔽：`x < 0 ? -x : x` 里的 `-x` 只否定 `a[i]`，`mean` 留在外面，负数分支整个算错。

```c file=main.c expect=WA
#include <stdio.h>

#define MAX_N 1000

#define SQR(x) x * x
#define ABS(x) x < 0 ? -x : x

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 2 || n > MAX_N) {
        return 0;
    }

    static int a[MAX_N];
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1 || a[i] < 0 || a[i] > 10000) {
            return 0;
        }
        sum += a[i];
    }

    int mean = (int)(sum / n);

    long long ssq = 0;
    long long mad = 0;
    for (int i = 0; i < n; i++) {
        ssq += SQR(a[i] - mean);
        mad += ABS(a[i] - mean);
    }

    printf("mean=%d\n", mean);
    printf("ssq=%lld\n", ssq);
    printf("mad=%lld\n", mad);
    return 0;
}
```

### 用 int 累加偏差平方和 [UB]
宏改对了，但 `ssq` 还是 `int`：`1000 × 10000² = 10¹¹` 远超 `int` 上限，有符号整数溢出是未定义行为，本平台会判 `UB` 并报 `signed integer overflow`。注意它在示例 1 上完全正常，只有数据变大才崩——这类"小数据能过"的 bug 最浪费时间。

```c file=main.c expect=UB
#include <stdio.h>

#define MAX_N 1000

#define SQR(x) ((x) * (x))
#define ABS(x) ((x) < 0 ? -(x) : (x))

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 2 || n > MAX_N) {
        return 0;
    }

    static int a[MAX_N];
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1 || a[i] < 0 || a[i] > 10000) {
            return 0;
        }
        sum += a[i];
    }

    int mean = (int)(sum / n);

    int ssq = 0;                    /* 错：10^11 装不进 int */
    long long mad = 0;
    for (int i = 0; i < n; i++) {
        ssq += SQR(a[i] - mean);
        mad += ABS(a[i] - mean);
    }

    printf("mean=%d\n", mean);
    printf("ssq=%d\n", ssq);
    printf("mad=%lld\n", mad);
    return 0;
}
```

### 把宏的参数当成函数形参来写 [CE]
把函数宏写成"函数原型"的样子——`#define SQR(int x) ...`——是初学者常见的混淆。宏的参数列表里只能是**标识符**，不能带类型，编译器会直接报 `invalid token in macro parameter list`。

```c file=main.c expect=CE
#include <stdio.h>

#define MAX_N 1000

#define SQR(int x) ((x) * (x))          /* 错：宏参数不能带类型 */
#define ABS(x) ((x) < 0 ? -(x) : (x))

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 2 || n > MAX_N) {
        return 0;
    }

    static int a[MAX_N];
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
        sum += a[i];
    }

    int mean = (int)(sum / n);
    long long ssq = 0;
    long long mad = 0;
    for (int i = 0; i < n; i++) {
        ssq += SQR(a[i] - mean);
        mad += ABS(a[i] - mean);
    }

    printf("mean=%d\n", mean);
    printf("ssq=%lld\n", ssq);
    printf("mad=%lld\n", mad);
    return 0;
}
```

### 在宏的实参里写自增 [UB]
`SQR(a[i++])` 展开成 `((a[i++]) * (a[i++]))`：同一个 `i` 在一个完整表达式里被修改两次，两次修改之间**没有先后顺序**，这是未定义行为；就算某次"看起来算对了"，`i` 也被加了两次。宏的参数可能被求值多次，实参必须是没有副作用的纯值——这是函数宏与函数最本质的区别之一。

### 生成 boundary 1000 个分数：999 个满分 + 1 个 0 分
```js gen
/* 长输入用生成器算，避免手写一长串数字时数错个数 */
const n = 1000;
const a = new Array(n).fill(10000);
a[n - 1] = 0;

let sum = 0;
for (const x of a) sum += x;
const mean = Math.trunc(sum / n);

let ssq = 0;
let mad = 0;
for (const x of a) {
  const d = x - mean;
  ssq += d * d;
  mad += Math.abs(d);
}

return [{
  kind: 'boundary',
  category: '999 个满分加一个 0 分',
  input: `${n}\n${a.join(' ')}\n`,
  output: `mean=${mean}\nssq=${ssq}\nmad=${mad}\n`,
}];
```
