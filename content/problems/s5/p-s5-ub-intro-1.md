## 题目描述
给定长度为 `n` 的整数数组和 `q` 个下标查询。对每个查询：如果下标在 `[0, n-1]` 之内，输出该位置的元素；否则输出 `OUT`。

这道题本身只是"查表"，但它对应真实代码里最常见的一类越界 bug：**先把元素取出来，再判断下标合不合法**。"取出来"那一步已经访问了数组，如果下标越界，程序在判界之前就已经进入未定义行为——后面再怎么判都晚了。

请把判界写在访问之前，并且只对合法的下标做 `a[idx]`。

## 输入格式
第一行一个整数 `n`。
第二行 `n` 个整数，依次是 `a[0]` 到 `a[n-1]`，用空格分隔。
第三行一个整数 `q`。
接下来 `q` 行，每行一个整数 `idx`，表示一次查询的下标。

## 输出格式
对每个查询输出一行：
- 若 `0 <= idx < n`，输出 `a[idx]`；
- 否则输出 `OUT`。

## 数据范围
1 ≤ n ≤ 200
-1000000000 ≤ a[i] ≤ 1000000000
1 ≤ q ≤ 1000
-1000000000 ≤ idx ≤ 1000000000

下标可能是负数，也可能远大于 `n`。只有 `0 <= idx < n` 时才允许访问 `a[idx]`；`idx == n` 已经是越界，不能"顺手读一下再判断"。

## 示例
### 示例 1

### 示例 2（边界：只有一个元素）
```in

```

```out
7

OUT
```
> `n = 1` 时只有下标 `0` 合法。`1` 恰好是"长度本身"，`-1` 是"最小的越界负数"，这两条边界最容易写错。

## 提示
### 第 1 层
"合法下标"是两个条件同时成立：`idx >= 0` 和 `idx < n`。少写任何一个，都会在某些查询上访问到数组外面。

### 第 2 层
先把判断结果存下来，再决定做什么：

```c
if (idx >= 0 && idx < n) {
    printf("%d\n", a[idx]);      /* 只有这里才允许访问 */
} else {
    printf("OUT\n");
}
```

不要写成 `int v = a[idx];` 之后再判断——那行已经在越界读了。

### 第 3 层
`|idx|` 最大可以到 10⁹，所以：
- 不要用 `unsigned` 存下标，`-1` 会变成 4294967295，比较就失去意义；
- 不要写 `idx <= n`，那会让 `idx == n` 通过检查；
- 不要把"越界"的答案写成 0，题目要求的是 `OUT`。

## 参考代码
```c file=main.c
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > MAXN) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1 || q < 1 || q > 1000) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        if (idx >= 0 && idx < n) {          /* 判界在前 */
            printf("%d\n", a[idx]);         /* 访问在后 */
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```

## 初始代码
```c file=main.c
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > MAXN) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1 || q < 1 || q > 1000) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        int v = a[idx];                     /* TODO: 越界时这一行已经是 UB，判界必须在访问之前 */
        if (idx >= 0 && idx < n) {
            printf("%d\n", v);
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```

## 复杂度
时间 O(n + q)：读入数组一遍，每个查询 O(1)。
空间 O(n)：一个定长数组。

## 常见错误
### 先取元素、后判界 [UB]
把 `int v = a[idx];` 写在 `if` 之前，是最典型的"顺序反了"。样例里所有下标都合法，程序看起来完全正常；一旦遇到 `idx == n` 或负数，那行读取就是未定义行为——本平台的 UBSan 会直接报 `index N out of bounds`。

```c file=main.c expect=UB
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        int v = a[idx];                     /* 错：先访问 */
        if (idx >= 0 && idx < n) {          /* 后判界，已经晚了 */
            printf("%d\n", v);
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```

### 只判上界、漏掉负下标 [UB]
`if (idx < n)` 只挡住了"太大"的情况，`idx = -1` 照样能通过，然后 `a[-1]` 越界。下界和上界必须同时判断。

```c file=main.c expect=UB
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        if (idx < n) {                      /* 错：没判 idx >= 0 */
            printf("%d\n", a[idx]);
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```

### 下界写成 `idx > 0` [WA]
`idx > 0` 把下标 `0` 也判成了越界：查询 `0` 会输出 `OUT`，而正确答案是 `a[0]`。这类"差一个"的错误在样例里不一定看得出来，但在隐藏用例里必然出错。

```c file=main.c expect=WA
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        if (idx > 0 && idx < n) {           /* 错：下标 0 被漏掉了 */
            printf("%d\n", a[idx]);
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```

### 用 0 表示"越界" [WA]
题目要求输出 `OUT`。如果为了"方便"把越界当成 0 输出，那么"下标越界"和"元素恰好是 0"就无法区分，输出会大范围出错。

### 上界写成 `idx <= n` [WA]
`idx == n` 是"刚好越过最后一个元素"的下标。`idx <= n` 会让它通过检查，接着 `a[n]` 就访问到了 `n` 个有效元素之外的位置：当 `n` 比数组声明长度小时，读到的是数组尾部没赋过值的槽位，输出错得莫名其妙；当 `n` 恰好等于声明长度时，这次访问会真的越出数组，被 UBSan 抓成 `UB`。

```c file=main.c expect=WA
#include <stdio.h>

#define MAXN 200

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int a[MAXN];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int q;
    if (scanf("%d", &q) != 1) {
        return 0;
    }
    for (int k = 0; k < q; k++) {
        int idx = 0;
        if (scanf("%d", &idx) != 1) {
            return 0;
        }
        if (idx >= 0 && idx <= n) {          /* 错：idx == n 也通过了 */
            printf("%d\n", a[idx]);
        } else {
            printf("OUT\n");
        }
    }
    return 0;
}
```
