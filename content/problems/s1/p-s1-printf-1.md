## 题目描述
读入一个无符号整数 n，按下面的要求输出五行：

1. 宽度为 10、**左对齐**，两边加方括号，例如 `[255       ]`；
2. 宽度为 10、**右对齐**，两边加方括号，例如 `[       255]`；
3. 宽度为 10、右对齐且**不足部分补 0**，两边加方括号，例如 `[0000000255]`；
4. `0x` 加上 **8 位大写十六进制**（不足 8 位补 0），例如 `0x000000FF`；
5. 带前缀 0 的八进制，例如 `0377`；n 为 0 时输出 `0`。

注意：本题按**原样**比较输出，每行末尾不能有多余的空格（方括号里的空格当然要有）。

## 输入格式
一行，一个整数 n。

## 输出格式
五行，见题目描述。

## 数据范围
0 ≤ n ≤ 4294967295

## 示例
### 示例 1
```in
255
```
```out
[255       ]
[       255]
[0000000255]
0x000000FF
0377
```

### 示例 2（边界：0）
```in
0
```
```out
[0         ]
[         0]
[0000000000]
0x00000000
0
```

## 提示
### 第 1 层
所有要求都能用一个格式说明符加上标志、宽度完成，不需要任何计算。

### 第 2 层
n 是无符号数，基本说明符是 `%u`；十六进制大写用 `%X`，八进制用 `%o`。标志：`-` 左对齐，`0` 补零，`#` 加进制前缀。

### 第 3 层
五个格式依次是 `[%-10u]`、`[%10u]`、`[%010u]`、`0x%08X`、`%#o`。（`%#o` 对 0 只输出一个 `0`，正好符合要求。）

## 参考代码
```c file=main.c
#include <stdio.h>

int main(void) {
    unsigned int n;
    if (scanf("%u", &n) != 1) {
        return 0;
    }
    printf("[%-10u]\n", n);   /* - ：左对齐 */
    printf("[%10u]\n", n);    /* 默认右对齐 */
    printf("[%010u]\n", n);   /* 0 ：用 0 填充 */
    printf("0x%08X\n", n);    /* 大写十六进制，至少 8 位，不足补 0 */
    printf("%#o\n", n);       /* # ：八进制加前缀 0（n 为 0 时只输出 0） */
    return 0;
}
```

## 复杂度
O(1)。本题考查 printf 的格式说明符、宽度和标志。

## 常见错误
### 用 %d 输出无符号数 [WA]
n 大于 2147483647 时，`%d` 会把它解释成负数。（`-Wall` 会给出格式不匹配的警告。）
```c file=main.c expect=WA
#include <stdio.h>

int main(void) {
    unsigned int n;
    if (scanf("%u", &n) != 1) {
        return 0;
    }
    printf("[%-10d]\n", n);
    printf("[%10d]\n", n);
    printf("[%010d]\n", n);
    printf("0x%08X\n", n);
    printf("%#o\n", n);
    return 0;
}
```

### 十六进制用了小写 %x [WA]
`%x` 输出 `ff`，题目要求大写 `FF`。
```c file=main.c expect=WA
#include <stdio.h>

int main(void) {
    unsigned int n;
    if (scanf("%u", &n) != 1) {
        return 0;
    }
    printf("[%-10u]\n", n);
    printf("[%10u]\n", n);
    printf("[%010u]\n", n);
    printf("0x%08x\n", n);
    printf("%#o\n", n);
    return 0;
}
```

### 八进制手写前缀 "0%o" [WA]
n 为 0 时输出 `00`，而题目要求 `0`。`%#o` 会正确处理这种情况。
```c file=main.c expect=WA
#include <stdio.h>

int main(void) {
    unsigned int n;
    if (scanf("%u", &n) != 1) {
        return 0;
    }
    printf("[%-10u]\n", n);
    printf("[%10u]\n", n);
    printf("[%010u]\n", n);
    printf("0x%08X\n", n);
    printf("0%o\n", n);
    return 0;
}
```

### 用 %#X 代替 0x%08X [WA]
`%#X` 输出的前缀是大写的 `0X`，而且对 0 不加前缀；`%#010X` 的宽度包含了前缀。直接写 `0x%08X` 最清楚。
