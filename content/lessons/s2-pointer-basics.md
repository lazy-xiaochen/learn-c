## 讲解

### 变量也有"门牌号"
程序运行时，每个变量都占着内存里的一块地方，这块地方的起始编号就是它的**地址**。用取地址运算符 `&` 可以拿到它：

```c run id=addr nocheck reason="打印的是变量的地址，每次运行都可能不同"
#include <stdio.h>

int main(void) {
    int x = 42;
    printf("x = %d\n", x);
    printf("&x = %p\n", (void *)&x);   /* 地址每次运行可能不同 */
    return 0;
}
```

`%p` 是专门打印地址的格式符。地址的具体数值（比如 0x61fe1c）每次运行都可能变化，这是操作系统故意安排的，不用记住具体数字，重点是理解**每个变量都有地址**。

### 指针：专门存地址的变量
**指针**是一种变量，它存的内容是另一个变量的地址。声明时用 `*` 表示"这是指针"，并写明它指向什么类型：

```c
int x = 42;
int *p = &x;      /* p 里存着 x 的地址，即 p 指向 x */
```

- `p` 的值是地址（`&x`）；
- `*p` 表示"顺着地址找到那个变量"，也就是 `x` 本身。这个操作叫**解引用**。

```c run id=deref
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;

    printf("x = %d\n", x);
    printf("*p = %d\n", *p);    /* 通过指针读 x */

    *p = 7;                     /* 通过指针写 x */
    printf("修改后 x = %d\n", x);
    return 0;
}
```
```output
x = 42
*p = 42
修改后 x = 7
```

`*p = 7` 改的是 `p` 指向的那个变量，也就是 `x`。**指针本身没有复制 x，它只是记住了 x 在哪里**——所以通过指针修改，原变量就真的变了。

```memory title="int x = 42; int *p = &x;（64 位环境下 int 占 4 字节、指针占 8 字节）"
地址     | 内容        | 变量 | 说明
0x1000   | 42          | x    | 一个普通的 int
0x1008   | 0x1000      | p    | 指针，存的是 x 的地址
```

### 指针可以改变指向
指针变量本身也可以被重新赋值，让它指向别的变量：

```c run id=retarget
#include <stdio.h>

int main(void) {
    int a = 1, b = 2;
    int *p = &a;

    printf("现在指向 a：%d\n", *p);
    p = &b;                        /* 改成指向 b */
    printf("现在指向 b：%d\n", *p);
    return 0;
}
```
```output
现在指向 a：1
现在指向 b：2
```

注意 `p = &b;` 改的是"指向哪里"，`*p = 3;` 改的是"指向的那个变量的值"。这两件事完全不同，是初学阶段最容易混的地方。

### 空指针：NULL
如果一个指针暂时不指向任何变量，应该把它赋成 `NULL`（C 标准定义的"空指针"）。**解引用空指针会直接崩溃**，所以用之前要先检查：

```c run id=null
#include <stdio.h>

int main(void) {
    int *p = NULL;

    if (p != NULL) {
        printf("%d\n", *p);        /* 只有非空才解引用 */
    } else {
        printf("p 是空指针，不能解引用\n");
    }
    return 0;
}
```
```output
p 是空指针，不能解引用
```

### 指针的类型很重要
`int *` 和 `char *` 都是指针，都占 8 字节，但"顺着地址取几个字节、按什么格式解释"由类型决定。所以：

- `int *p` 只能指向 `int`（不能把 `double` 的地址直接赋给它）；
- `*p` 取出来是 `int`，可以当普通 `int` 用；
- 指针的步长也和类型有关（下一节讲）。

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra ptr.c -o ptr
./ptr
```

本平台用 Clang，命令等价：`clang -std=c17 -Wall -Wextra ptr.c -o ptr`。
`-Wall` 会检查指针类型不匹配、未初始化指针等常见错误，务必打开。

## 常见错误

### 声明了指针却没有让它指向任何地方
`int *p; *p = 5;` 里的 `p` 里是随机值，`*p = 5` 会往一个随机地址写数据，属于未定义行为。指针要么在声明时初始化（`int *p = &x;`），要么先赋 `NULL` 并在使用前检查。

### 解引用空指针
```c run id=null-deref expect=UB
#include <stdio.h>

int main(void) {
    int *p = NULL;
    *p = 5;                 /* 空指针不能解引用 */
    printf("%d\n", *p);
    return 0;
}
```

### 把 `&` 和 `*` 用反
`p = &x` 是"让 p 指向 x"，`*p = 5` 是"把 5 写进 p 指向的变量"。写 `p = 5` 会得到类型不匹配的编译错误；写 `*p = &x` 同样错误。

### 以为 `*p` 和 `p` 是一回事
`p` 是地址（打印出来是一串十六进制），`*p` 是那个地址上的值。`printf("%d", p)` 在 64 位环境下格式也不对，应该用 `%p` 打印 `(void *)p`。

## 客观题

### q-s2-pointer-basics-1 single
执行下面的代码，输出是什么？

```c
int x = 5;
int *p = &x;
*p = *p + 1;
printf("%d\n", x);
```

- [x] `6`
  > 正确。`*p` 就是 x，`*p + 1` 算出 6 再写回 x，所以 x 变成 6。
- [ ] `5`
  > `*p = ...` 确实修改了 x，不会保持原值。
- [ ] 程序崩溃
  > p 指向的是有效变量 x，解引用是安全的。
- [ ] 编译错误
  > 语法和类型都正确，能正常编译。
