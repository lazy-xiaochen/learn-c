## 讲解

### 五个算术运算符
| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减（或取负） | `7 - 2`、`-x` | 5 |
| `*` | 乘 | `7 * 2` | 14 |
| `/` | 除 | `7 / 2` | **3**（整数相除，结果是整数） |
| `%` | 取余（模） | `7 % 2` | 1（**只能用于整数**） |

### 整数除法向零截断
两个整数相除时，结果的小数部分被直接丢弃，也就是**向 0 的方向取整**（C99 起标准明确规定）。对负数来说，这和数学上的"向下取整"不同：

```c run id=div
#include <stdio.h>

int main(void) {
    printf("%d %d\n", 7 / 2, 7 % 2);
    printf("%d %d\n", -7 / 2, -7 % 2);
    printf("%d %d\n", 7 / -2, 7 % -2);
    printf("%d %d\n", -7 / -2, -7 % -2);
    return 0;
}
```
```output
3 1
-3 -1
-3 1
3 -1
```

规律是：**余数的符号与被除数（左边的数）相同**，并且永远满足

> (a / b) × b + a % b == a

所以 `-7 % 2` 是 -1 而不是 1。如果你需要一个"永远非负"的余数（比如计算星期几、循环下标），要自己调整：`((a % b) + b) % b`（b > 0 时）。

### 取出数字的每一位
`/ 10` 去掉最后一位，`% 10` 取出最后一位，这是整数运算最常见的用法之一：

```c run id=digits stdin="2026"
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 1;
    printf("个位 %d\n", n % 10);
    printf("十位 %d\n", n / 10 % 10);
    printf("百位 %d\n", n / 100 % 10);
    printf("千位 %d\n", n / 1000 % 10);
    return 0;
}
```
```output
个位 6
十位 2
百位 0
千位 2
```

### 取余最常用的地方：判断整除
C 里没有"能被整除"这个运算符，判断方法一律是看 `%` 的结果是不是 0。奇偶、末位数字、能不能被某个数整除，全靠取余：

```c run id=mod-use stdin="12"
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 1;
    printf("是偶数：%d\n", n % 2 == 0);
    printf("能被 3 整除：%d\n", n % 3 == 0);
    printf("个位数：%d\n", n % 10);
    return 0;
}
```
```output
是偶数：1
能被 3 整除：1
个位数：2
```

比较表达式的结果是 1（真）或 0（假），所以可以直接用 `%d` 把它打印出来看。这在你学条件判断之前很有用：不用写 `if`，先确认自己的判断条件算得对不对。

初学者最容易犯的错是把 `n % 2 == 0` 简写成 `n % 2`：偶数时它得 0，奇数时得 1，**恰好和"真 / 假"反过来**——拿它去当条件，判断会完全倒过来。多写一个 `== 0` 不能省。

### 浮点数的除法与取余
只要有一个操作数是浮点数，`/` 就是普通的除法。`%` 不能用于浮点数（编译错误），浮点数取余用 `<math.h>` 里的 `fmod`：

```c run id=fdiv
#include <stdio.h>
#include <math.h>

int main(void) {
    printf("%.2f\n", 7.0 / 2);
    printf("%.2f\n", fmod(7.5, 2.0));
    return 0;
}
```
```output
3.50
1.50
```

### 除以零
整数除以 0（`/` 或 `%`）是**未定义行为**，在 x86 电脑上通常会让程序直接崩溃。本平台的检测工具会报告它：

```c run id=divzero expect=UB stdin="10 0"
#include <stdio.h>

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) return 1;
    printf("%d\n", a / b);
    return 0;
}
```

另一个不那么显眼的除法陷阱：`INT_MIN / -1` 的结果是 2147483648，超出了 `int` 的范围，同样是未定义行为（x86 上也会崩溃）。

浮点数除以 0 则不会崩溃，结果是 `inf`（无穷大）或 `nan`（"不是一个数"）。

### 算术运算易错点清单
| 你可能以为 | 实际上 | 正确做法 |
|---|---|---|
| `7 / 2` 得 3.5 | 两个 `int` 相除，结果还是 `int`，得 3 | 写 `7 / 2.0` 或 `(double)7 / 2` |
| `-7 % 3` 得 2 | 得 -1，余数符号跟被除数走 | 要非负余数：`((a % m) + m) % m` |
| `%` 可以用在小数上 | 只能用于整数，否则编译错误 | 浮点取余用 `fmod` |
| `a / b * c` 和 `a * c / b` 一样 | 前者可能先除成 0，后面怎么乘还是 0 | 先乘后除，或者改用浮点 |
| `7 / 2 * 2` 还是 7 | 得 6：中间结果 3 已经把 0.5 丢了 | 先乘后除：`7 * 2 / 2` |
| `a / 0` 会得到 0 或者报个错 | 未定义行为，通常直接崩溃 | 除之前先判断 `b != 0` |

## 常见错误

### 以为负数取余结果是正数
`-7 % 3` 是 -1，不是 2。需要非负余数时写 `((a % m) + m) % m`。

### 对浮点数使用 %
```c run id=float-mod expect=CE
#include <stdio.h>

int main(void) {
    double x = 7.5;
    printf("%f\n", x % 2);
    return 0;
}
```

### 先除后乘丢失精度
计算百分比时 `count / total * 100`：如果 count 小于 total，`count / total` 先得到 0，结果永远是 0。应当先乘后除 `count * 100 / total`，或者用浮点数 `count * 100.0 / total`。

### 拆数字时 / 和 % 的顺序写反
取十位要写 `n / 10 % 10`：先用 `/` 把不要的个位"削掉"，再用 `%` 取当前的末位。写成 `n % 10 / 10` 就永远是 0——`n % 10` 得到的是 0 到 9，再除以 10 当然还是 0。记住顺序：**先削位，再取位**。

## 客观题

### q-s1-arith-ops-1 single
表达式 `-17 / 5` 和 `-17 % 5` 的值分别是：
- [ ] -4 和 3
  > 这是"向下取整"的结果（Python 等语言如此），但 C 的整数除法向 0 截断。
- [x] -3 和 -2
  > 正确。-17 / 5 = -3.4，向 0 截断为 -3；余数满足 (-3) × 5 + r = -17，所以 r = -2，符号与被除数相同。
- [ ] -3 和 2
  > 余数必须满足 (a / b) × b + a % b == a，(-3) × 5 + 2 = -13，不等于 -17。
- [ ] 结果由编译器决定
  > C89 中负数除法的取整方向确实由实现决定，但 C99 起标准明确规定为向 0 截断。
