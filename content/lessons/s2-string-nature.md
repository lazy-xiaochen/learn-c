## 讲解

### C 没有"字符串类型"

在 Python、Java 里，字符串是一个独立的类型，自带长度信息。C 没有这个福利：C 的字符串不是类型，而是一个**约定**——

> 一段连续的 `char`，最后一个字符是 `'\0'`（编码为 0 的字节），前面的字符都不是 `'\0'`。

就这么简单。C 的字符串函数（`printf("%s")`、`strlen`、`strcmp`……）都不认识"数组长度"这个概念，它们只会**从首地址开始一个字节一个字节往后走，直到遇见 `'\0'` 为止**。知道这一点，后面所有"字符串为什么会越界""为什么少一个字节就乱码"的问题都能解释。

### 字符 'a' 与字符串 "a" 不是一回事

- `'a'` 是**字符常量**，类型是 `int`，值等于字符 a 的编码（ASCII 是 97）。
- `"a"` 是**字符串字面量**，它在内存里占 **2 个字节**：`'a'` 和结尾的 `'\0'`。

```c run id=char-vs-string
#include <stdio.h>

int main(void) {
    char c = 'a';      /* 一个字符，1 字节 */
    char s[] = "a";    /* 一个字符串，2 字节：'a' 和 '\0' */

    printf("字符 c 的编码是 %d\n", c);
    printf("字符串 s[0] 的编码是 %d，s[1] 的编码是 %d\n", s[0], s[1]);
    return 0;
}
```
```output
字符 c 的编码是 97
字符串 s[0] 的编码是 97，s[1] 的编码是 0
```

`s[1]` 就是那个结束标记 `'\0'`。它占内存，但**不算一个可见字符**，也不计入字符串长度。

### `'\0'` 是"到此为止"的信号

下面的程序把 `"cat"` 存进数组，再分别看第 4 个字节和用 `%s` 打印。注意 `%s` 打印到 `s[3]` 就停了，后面的内容与它无关：

```c run id=stop-at-null
#include <stdio.h>

int main(void) {
    char s[] = "cat";

    printf("%s\n", s);
    printf("s[2] = %c，s[3] = %d\n", s[2], s[3]);
    printf("用 %%s 打印时，遇到 s[3] 就结束了\n");
    return 0;
}
```
```output
cat
s[2] = t，s[3] = 0
用 %s 打印时，遇到 s[3] 就结束了
```

一个字符数组是不是"字符串"，不取决于它有几个字符，而取决于**里面有没有 `'\0'`**。同样存 `c`、`a`、`t` 三个字节，有 `'\0'` 就是字符串，没有就只是三个普通的 `char`。

### 字符就是小整数：ASCII 编码

`char` 本质上是一个整数类型，字符只是"这个整数对应哪个字形"的约定。ASCII 里有三条规律值得记住：

- `'0'` 到 `'9'` 的编码是连续的 48–57，所以 `c - '0'` 能把数字字符转成数值；
- 大写字母 `'A'`–`'Z'` 和小写字母 `'a'`–`'z'` 各自连续；
- 同一个字母的大写与小写相差 32，所以 `'a' - 'A' == 32`。

```c run id=ascii
#include <stdio.h>

int main(void) {
    char s[] = "2026";

    for (int i = 0; s[i] != '\0'; i++) {
        printf("'%c' 的编码是 %d\n", s[i], s[i]);
    }
    printf("'7' - '0' = %d\n", '7' - '0');
    printf("'a' - 'A' = %d\n", 'a' - 'A');
    return 0;
}
```
```output
'2' 的编码是 50
'0' 的编码是 48
'2' 的编码是 50
'6' 的编码是 54
'7' - '0' = 7
'a' - 'A' = 32
```

这就是为什么判断一个字符是不是数字，既可以写 `c >= '0' && c <= '9'`，也可以直接调用 `<ctype.h>` 里的 `isdigit(c)`——后者内部也是在比较这段编码区间。

### 字符数组的几种初始化方式

```c
char a[] = "cat";                /* 自动分配 4 字节：c a t \0 */
char b[4] = {'c', 'a', 't', '\0'};  /* 等价：显式写出结束符 */
char c[3] = {'c', 'a', 't'};     /* 只有 3 个 char，不是字符串 */
char d[8] = "cat";               /* 8 字节：c a t \0 0 0 0 0 */
```

用字符串字面量初始化时，编译器会自动把 `'\0'` 放进去；用花括号逐个字符初始化时，`'\0'` 要自己写。数组比字符串长时，剩下的字节会被补 0，所以 `d[3]` 之后全是 0。

```c run id=fixed-width
#include <stdio.h>

int main(void) {
    char a[] = "cat";                /* 恰好 4 字节 */
    char b[8] = "cat";               /* 8 字节，不足的部分补 0 */
    char c[3] = {'c', 'a', 't'};     /* 只是 3 个 char */

    printf("sizeof a = %zu\n", sizeof a);
    printf("sizeof b = %zu\n", sizeof b);
    printf("sizeof c = %zu\n", sizeof c);
    printf("b[3] = %d，b[7] = %d\n", b[3], b[7]);
    printf("c[0..2] = %c%c%c\n", c[0], c[1], c[2]);
    return 0;
}
```
```output
sizeof a = 4
sizeof b = 8
sizeof c = 3
b[3] = 0，b[7] = 0
c[0..2] = cat
```

`sizeof` 在这里只是用来数"这个数组占几个字节"，下一节讲 `sizeof` 与 `strlen` 的区别时会展开。这里先记住：**`"cat"` 需要 4 个字节，不是 3 个。**

```memory title="char a[] = \"cat\"; 与 char c[3] = {'c','a','t'}; 的内存示意（地址仅为示意，实际每次运行可能不同）"
地址   | 内容        | 变量  | 说明
0x1000 | 'c' (99)    | a[0] | 字符 c
0x1001 | 'a' (97)    | a[1] | 字符 a
0x1002 | 't' (116)   | a[2] | 字符 t
0x1003 | '\0' (0)    | a[3] | 结束标记，sizeof a = 4
0x2000 | 'c' (99)    | c[0] | 只是 char
0x2001 | 'a' (97)    | c[1] | 只是 char
0x2002 | 't' (116)   | c[2] | 后面没有第 4 个字节，不能当字符串用
```

### 忘记 `'\0'` 会发生什么

如果用手动方式填字符却忘了补结束符，`printf("%s", s)`、`strlen(s)` 甚至 `strcmp` 都会**越过数组末尾继续往后读**，直到碰巧遇到一个 0。这是典型的未定义行为：可能打印出一串乱码，可能读到别的变量，也可能直接崩溃。

判断"有没有结束符"本身可以安全地做——只要把扫描限制在数组长度之内：

```c run id=missing-null
#include <stdio.h>

int main(void) {
    char bad[3] = {'c', 'a', 't'};
    int found = 0;

    for (int i = 0; i < 3; i++) {
        if (bad[i] == '\0') {
            found = 1;
        }
    }
    if (found) {
        printf("可以当字符串用\n");
    } else {
        printf("3 个字节里没有 '\\0'，不能当字符串用\n");
    }
    return 0;
}
```
```output
3 个字节里没有 '\0'，不能当字符串用
```

所以，只要准备把一段 `char` 当字符串用，就必须保证：**数组长度至少是"字符个数 + 1"**，并且那多出来的 1 个字节确实被写成了 `'\0'`。

### 三个必须养成的习惯

1. **给结束符留位置**：想存 10 个字符，就声明 `char s[11]` 起步。
2. **手动复制/填字符后立刻补 `'\0'`**：例如复制了 `n` 个字符，就写 `buf[n] = '\0';`。
3. **不确定就检查**：在调用字符串函数前，先确认数组里真的有结束符（比如像上面那样在长度范围内扫一遍）。

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra string.c -o string
./string
```

本平台使用 Clang，等价命令：`clang -std=c17 -Wall -Wextra string.c -o string`。

建议打开 `-Wall -Wextra`：把字符常量 `'a'` 误写成字符串字面量 `"a"`、用 `%s` 打印单个 `char`、忘记包含 `<string.h>` 等问题，编译器大多会直接提示。运行前也可以先用 `sizeof` 确认数组容量，再决定是否能用 `%s` 安全打印。

## 常见错误

### 把字符 `'a'` 和字符串 `"a"` 混用

`printf("%c", "a")` 传进去的是字符串的地址而不是字符，`printf("%s", 'a')` 则把 97 当成地址去读内存。前者通常能编译但有警告，后者往往直接崩溃。记住：`%c` 收一个字符，`%s` 收一个"以 `'\0'` 结尾的地址"。

### 数组长度算漏了 `'\0'`

想存 `"cat"` 却写成 `char s[3] = "cat";`。C 允许这种初始化，但结束符没有地方放，`s` 只是 3 个字符，不能当字符串用。`printf("%s", s)` 会继续读数组之外的内存。

### 以为 `'\0'` 就是字符 `'0'`

`'\0'` 的编码是 0，`'0'` 的编码是 48。判断结束标记要写 `s[i] == '\0'`，写成 `s[i] == '0'` 会在数字 0 的位置提前停止（或者永远不停）。

### 手动填完字符后忘记补结束符

```c
char buf[8];
for (int i = 0; i < 5; i++) {
    buf[i] = "hello"[i];
}
printf("%s\n", buf);   /* 错：buf 没有 '\0' */
```

复制完一定要写 `buf[5] = '\0';`。这类错误在输入较短时可能"看起来正常"，换一个输入就变成乱码。

## 客观题

### q-s2-string-nature-1 single

下面哪个声明得到的数组**可以**直接作为字符串传给 `printf("%s", ...)`？

- [ ] `char a[3] = {'c', 'a', 't'};`
  > 三个字符占满了全部空间，没有 `'\0'`。它只是 3 个 `char`，`%s` 会越过数组末尾继续读。
- [x] `char b[4] = {'c', 'a', 't', '\0'};`
  > 正确。第 4 个字节显式写入了 `'\0'`，这是一个合法的 C 字符串。
- [ ] `char c[3] = "cat";`
  > 数组只有 3 字节，放不下结尾的 `'\0'`，初始化后 `c` 的内容仍是 `c`、`a`、`t`，不是字符串。
- [ ] `char d[2] = {'c', 'a'};`
  > 只有两个字符，没有结束标记。字符串至少要"字符个数 + 1"个字节。
