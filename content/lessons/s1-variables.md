## 讲解

### 变量是一块有名字的内存
程序运行时，数据存放在内存里。**变量**就是给一块内存起的名字：通过名字读写这块内存，而不用关心它的具体地址。变量的**类型**决定了这块内存有多大、里面的二进制位按什么规则解释。

```c
int age = 18;      /* 申请一块 int 大小（4 字节）的内存，起名 age，存入 18 */
double h = 1.75;   /* 申请 8 字节，起名 h，存入 1.75 */
```

```memory title="int age = 18; double h = 1.75; 之后（地址仅为示意）"
地址      | 内容   | 变量
0x1000    | 18     | age（4 字节）
0x1008    | 1.75   | h（8 字节）
```

### 声明、初始化与赋值
| 写法 | 名称 | 含义 |
|---|---|---|
| `int x;` | 声明（定义） | 申请内存，但**不放入确定的值** |
| `int x = 5;` | 声明并初始化 | 申请内存的同时放入 5 |
| `x = 7;` | 赋值 | 把 7 写入已经存在的变量，旧值被覆盖 |

```c run id=assign
#include <stdio.h>

int main(void) {
    int score = 60;          /* 初始化 */
    printf("开始：%d\n", score);
    score = 85;              /* 赋值：旧值 60 被覆盖 */
    printf("修改后：%d\n", score);
    score = score + 10;      /* 先读出旧值 85，加 10，再写回 */
    printf("加分后：%d\n", score);
    return 0;
}
```
```output
开始：60
修改后：85
加分后：95
```

`score = score + 10` 在数学里不成立，但在 C 里 `=` 是**赋值**而不是"相等"：先计算右边，再把结果存进左边。

### 先声明，后使用
编译器从上往下读你的代码。读到某一行的名字时，它必须已经知道"这个名字是什么类型、有多大"，否则拒绝编译。所以**声明必须写在第一次使用之前**：

```c run id=use-before-decl expect=CE
#include <stdio.h>

int main(void) {
    total = 100;         /* 这时编译器还不知道 total 是什么 */
    int total = 0;       /* 声明写在后面，已经来不及了 */
    printf("%d\n", total);
    return 0;
}
```

报错是 `use of undeclared identifier 'total'`（使用了未声明的标识符）。有些语言允许"用到就自动创建变量"，C 不允许：名字必须先由 `int total;` 这样的声明引进门。把声明换到第一句，程序立刻就能编译。

### 变量存的是"那一刻"的值
很多初学者把 `sum = a + b` 理解成数学里的等式，以为它建立了永久的关系。C 里的 `=` 只做一件事：**算一次，复制进去**。之后 a、b 再变，sum 也不会跟着变：

```c run id=independent
#include <stdio.h>

int main(void) {
    int a = 1, b = 2;
    int sum = a + b;      /* sum 拿到的是 1 + 2 = 3 这个结果 */
    a = 100;              /* 只改 a：sum 里存的是复制品，不受影响 */
    printf("a=%d b=%d sum=%d\n", a, b, sum);
    return 0;
}
```
```output
a=100 b=2 sum=3
```

从数学思维切换到编程思维，最需要跨过的就是这道坎：

| 数学里的想法 | C 里实际发生的 | 例子（执行后） |
|---|---|---|
| `x = x + 1` 不可能成立 | `=` 是赋值：先算右边，再写回左边 | x 从 5 变成 6 |
| `sum = a + b` 建立了永久的等式 | 只把**此刻**的 a + b 复制一份存进 sum | 之后改 a，sum 不变 |
| 名字差不多就是同一个量 | 名字区分大小写，拼错就是另一个名字 | `Total` 和 `total` 是两个变量 |
| 没赋值的量就当 0 用 | 局部变量的初值不确定，读它属于未定义行为 | 必须先给初值 |

所以想让 sum 反映新的 a、b，必须**再写一次** `sum = a + b;`。C 不会替你重新计算。

### 未初始化的局部变量
函数内部声明的变量（局部变量）如果没有初始化，里面是**不确定的值**（俗称"垃圾值"），读取它是未定义行为：每次运行、换个编译选项，结果都可能不同。编译器开启 `-Wall` 时通常会给出警告：

```c run id=uninit warnings=allow nocheck reason="读取未初始化变量的结果不确定"
#include <stdio.h>

int main(void) {
    int total;               /* 没有初始化 */
    total = total + 1;       /* 读取了不确定的值 */
    printf("%d\n", total);
    return 0;
}
```

**养成习惯：声明变量时就给它一个初始值。**

### 交换两个变量
交换 a 和 b 的值是最常见的操作之一。不能直接写 `a = b; b = a;`——第一句执行完，a 原来的值就被覆盖了。需要一个临时变量先把它保存起来：

```c run id=swap stdin="3 5"
#include <stdio.h>

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) return 1;
    int tmp = a;   /* 1. 先保存 a */
    a = b;         /* 2. a 得到 b 的值 */
    b = tmp;       /* 3. b 得到 a 原来的值 */
    printf("a=%d b=%d\n", a, b);
    return 0;
}
```
```output
a=5 b=3
```

### 命名规则
- 只能由字母、数字、下划线组成，**不能以数字开头**：`count2` 合法，`2count` 不合法；
- 区分大小写：`Score` 和 `score` 是两个变量；
- 不能使用关键字：`int`、`return`、`if` 等；
- 以下划线开头的名字（如 `_x`、`__y`）保留给编译器和标准库，不要使用。

好名字让代码自己说明含义：`studentCount`、`total_price` 比 `a`、`tmp2` 清楚得多。

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra vars.c -o vars
./vars
```

`-Wall` 能发现很多"使用了未初始化变量"的情况（`-Wuninitialized`），但不是全部，所以不能完全依赖编译器。

## 常见错误

### 一行声明多个变量时只初始化了最后一个
`int a, b = 0;` 只有 `b` 被初始化为 0，`a` 仍然是不确定的值。要都初始化，写成 `int a = 0, b = 0;`。

### 交换时顺序错误
`a = b; b = a;` 之后两个变量都等于 b 原来的值。

### 用"加减法交换"省掉临时变量
网上流传 `a = a + b; b = a - b; a = a - b;` 的写法，但 `a + b` 可能超出 `int` 的范围，发生有符号整数溢出（未定义行为）。用临时变量最清晰也最安全。

### 变量名大小写写错
声明的是 `int total = 0;`，后面却写成 `printf("%d\n", Total);`，编译器会报 `use of undeclared identifier 'Total'`。C **区分大小写**，`total`、`Total`、`TOTAL` 是三个毫不相干的变量。看到"未声明"的报错时，先和声明处逐字符对一遍拼写。

## 客观题

### q-s1-variables-1 single
执行 `int a, b = 3, c;` 之后，哪些变量有确定的值（假设它们是函数内的局部变量）？
- [ ] a、b、c 都是 3
  > 初始化只作用于紧挨着的那个变量，`= 3` 只属于 b。
- [ ] a、b、c 都是 0
  > 局部变量不会被自动初始化为 0（全局变量和 static 变量才会）。
- [x] 只有 b 是 3，a 和 c 的值不确定
  > 正确。读取 a 或 c 之前必须先给它们赋值。
- [ ] 编译错误：不能在一行声明多个变量
  > 用逗号分隔可以在一行声明多个同类型的变量，这是合法的。
