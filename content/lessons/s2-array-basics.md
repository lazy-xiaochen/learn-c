## 讲解

### 为什么要用数组
如果要存 5 个整数，可以声明 5 个变量；但存 100 个、10 万个呢？一个个起名字显然不行。

**数组**把**同一类型的多个元素**放在一起，并给它们一个共同的名字。元素在内存里**一个挨一个连续排列**，用**下标**区分：`a[0]` 是第 1 个，`a[1]` 是第 2 个……

```c run id=why
#include <stdio.h>

int main(void) {
    int a0 = 3, a1 = 1, a2 = 4, a3 = 1, a4 = 5;
    int sum = a0 + a1 + a2 + a3 + a4;
    printf("sum = %d\n", sum);
    return 0;
}
```
```output
sum = 14
```

这段代码能算对，但它**只适用于 5 个数**：换成 100 个数，就得写 100 个变量、100 次加法。数组解决的就是这个问题——用"名字 + 下标"表达"一组数"，再配合循环，个数多少都不用改代码。

### 定义、下标与初始化
定义格式：`类型 数组名[元素个数];`

```c run id=init
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};   /* 5 个元素，全部给出 */
    int b[5] = {7, 8};            /* 只写前 2 个，其余自动补 0 */
    int c[5] = {0};               /* 常见写法：全部清零 */

    for (int i = 0; i < 5; i++) printf("%d ", a[i]);
    printf("\n");
    for (int i = 0; i < 5; i++) printf("%d ", b[i]);
    printf("\n");
    for (int i = 0; i < 5; i++) printf("%d ", c[i]);
    printf("\n");
    return 0;
}
```
```output
3 1 4 1 5
7 8 0 0 0
0 0 0 0 0
```

三条必须记住的规则：

1. **下标从 0 开始**。`int a[5]` 的合法下标是 `0、1、2、3、4`，共 5 个；`a[5]` 已经越界了。
2. **元素个数必须是编译期就能确定的常量**（C99 起有"变长数组"这个例外，第 10 个知识点会讲，它有明显限制）。写 `int n = 5; int a[n];` 在严格模式下不是好习惯。
3. **只写了一部分初始值，剩下的自动补 0**；但**完全不写**（`int a[5];`）时，局部数组里的值是**不确定的**，不能直接读。

### 数组在内存里是连续的
`sizeof a` 得到的是**整个数组**占的字节数；`sizeof a[0]` 是**一个元素**的大小。两者相除就是元素个数——这也是 C 里获取数组长度的标准写法。

```c run id=layout
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    printf("sizeof(a) = %zu\n", sizeof a);
    printf("一个 int 占 %zu 字节\n", sizeof a[0]);
    printf("元素个数 = %zu\n", sizeof a / sizeof a[0]);
    return 0;
}
```
```output
sizeof(a) = 20
一个 int 占 4 字节
元素个数 = 5
```

因为元素是**连续存放**的，知道了首地址和每个元素的大小，就能算出任意元素的位置。这条性质是下一节"内存布局"和后面所有指针内容的基础。

```memory title="int a[5] = {10, 20, 30, 40, 50}; 在栈上的布局（每个 int 占 4 字节）"
地址     | 内容 | 变量
0x1000   | 10   | a[0]
0x1004   | 20   | a[1]
0x1008   | 30   | a[2]
0x100c   | 40   | a[3]
0x1010   | 50   | a[4]
```

### 用循环遍历数组
数组真正的威力在于**下标可以是变量**，所以能用循环统一处理每个元素。下面读入 n 个数并求和：

```c run id=traverse stdin="4\n10 20 30 40"
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 100) {
        return 0;
    }
    int a[100];
    for (int i = 0; i < n; i++) {
        if (scanf("%d", &a[i]) != 1) {
            return 0;
        }
    }
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i];
    }
    printf("一共 %d 个数，和是 %d\n", n, sum);
    return 0;
}
```
```output
一共 4 个数，和是 100
```

注意数组开的是 100，而实际只用了前 n 个。**开大一点、只用一部分**是常见做法；但要保证 `n <= 100`，否则还是会越界。

### 在数组里找最大值
"把第一个元素当作当前最大值，再逐个比较"是最常见的模式：

```c run id=max
#include <stdio.h>

int main(void) {
    int a[6] = {7, 3, 9, 2, 8, 4};
    int max = a[0];                        /* 先假设第 1 个最大 */
    for (int i = 1; i < 6; i++) {          /* 从第 2 个开始比 */
        if (a[i] > max) {
            max = a[i];
        }
    }
    printf("最大值是 %d\n", max);
    return 0;
}
```
```output
最大值是 9
```

关键点是 `max` 的初值取 `a[0]`，**不能取 0**：如果所有元素都是负数（比如 -5、-3、-9），初值 0 会让"最大值"永远是 0，而它根本不在数组里。

```bash
gcc -std=c17 -Wall -Wextra arr.c -o arr

```

本平台内置的是 Clang，命令等价：`clang -std=c17 -Wall -Wextra arr.c -o arr`。

## 常见错误

### 下标从 1 开始，或者循环写成 `i <= n`
`int a[5]` 的合法下标是 0–4。写 `for (int i = 1; i <= 5; i++) a[i] = 0;` 会先跳过后面的 `a[0]`，最后写到 `a[5]`——越界。循环的通用写法是 `for (int i = 0; i < n; i++)`。

下面这段故意越界写入 `a[5]`：编译时 Clang 会直接给出 `-Warray-bounds` 警告，运行时越界检查会让程序停下，判题结果是**未定义行为（UB）**。注意"能编译"不等于"没问题"——编译器只是警告，真正执行时行为完全不可控。

```c run id=oob expect=UB
#include <stdio.h>

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    a[5] = 99;              /* 合法下标只有 0..4 */
    printf("%d\n", a[5]);
    return 0;
}
```

### 把数组当成一个整体赋值
`int a[5], b[5]; a = b;` 是**编译错误**：数组名不能作为赋值的目标。要复制数组，必须逐个元素复制（或者用 `memcpy`，第 2 阶段的字符串部分会讲）。

### 用变量当元素个数
`int n = 5; int a[n];` 在 C99 之后是"变长数组"，虽然能编译，但它不能初始化、大小不能是 0 或负数，而且不同编译器的支持程度不一样。初学阶段统一用常量，例如 `int a[100];`。

### 直接读没初始化的数组元素
`int a[5]; printf("%d", a[0]);` 里的值是**不确定的**（不是 0）。局部变量不会自动清零，读了它就是未定义行为。

## 客观题

### q-s2-array-basics-1 single
执行下面的代码，输出是什么？

```c
int a[5] = {1, 2};
printf("%d %d %d\n", a[0], a[1], a[4]);
```

- [x] `1 2 0`
  > 正确。初始化列表给出了 a[0]、a[1]，其余元素被自动补 0，所以 a[4] 是 0。
- [ ] `1 2 不确定的值`
  > 用了初始化列表时，没有写到的元素会被补 0；只有完全不写初始化（`int a[5];`）时才是垃圾值。
- [ ] `1 2 0 0 0`
  > printf 里只写了三个 `%d`，所以只输出三个数。
- [ ] 编译错误，初始化元素个数少于数组长度不合法
  > 合法。部分初始化是 C 明确允许的写法，剩下的元素补 0。
