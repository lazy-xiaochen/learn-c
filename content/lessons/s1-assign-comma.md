## 讲解

### 赋值本身也是一个表达式
`x = 5` 不只是"把 5 存进 x"，它还是一个**表达式**，值就是赋给 x 的值。因此可以连续赋值；赋值运算符是**右结合**的，从右往左计算：

```c run id=chain
#include <stdio.h>

int main(void) {
    int a, b, c;
    a = b = c = 7;           /* 等价于 a = (b = (c = 7)) */
    printf("%d %d %d\n", a, b, c);
    int x;
    printf("%d\n", x = 42);  /* 赋值表达式的值是 42 */
    return 0;
}
```
```output
7 7 7
42
```

### 复合赋值
`x op= y` 等价于 `x = x op (y)`（但 x 只计算一次）：

| 写法 | 等价于 |
|---|---|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= a + b` | `x = x * (a + b)`（注意右边整体加了括号） |
| `x /= 2`、`x %= 2` | `x = x / 2`、`x = x % 2` |
| `x &= m`、`x \|= m`、`x ^= m`、`x <<= 1`、`x >>= 1` | 对应的位运算 |

### 自增与自减：前置和后置
`++x` 和 `x++` 都会让 x 加 1，区别在于**表达式的值**：

| 写法 | 名称 | x 的变化 | 表达式的值 |
|---|---|---|---|
| `++x` | 前置自增 | 加 1 | **加 1 之后**的新值 |
| `x++` | 后置自增 | 加 1 | **加 1 之前**的旧值 |

```c run id=incdec
#include <stdio.h>

int main(void) {
    int i = 5;
    int a = i++;   /* a 得到旧值 5，然后 i 变成 6 */
    printf("a=%d i=%d\n", a, i);
    int j = 5;
    int b = ++j;   /* j 先变成 6，b 得到新值 6 */
    printf("b=%d j=%d\n", b, j);
    return 0;
}
```
```output
a=5 i=6
b=6 j=6
```

单独成一条语句时（`i++;` 或 `++i;`），两者效果完全相同。

**规则**：在同一个表达式里，不要对同一个变量既使用 `++`/`--` 又在别处读取或修改它，例如 `i = i++`、`a[i] = i++`、`printf("%d %d", i, i++)`。这些都是**未定义行为**，下一节"优先级与结合性"会详细演示。

把自增放进 `printf` 里打印，能一眼看出"表达式的值"和"变量现在的值"是两回事：

```c run id=post-pre
#include <stdio.h>

int main(void) {
    int i = 1;
    printf("i++ 的值：%d\n", i++);   /* 先送出旧值 1，之后 i 变成 2 */
    printf("现在 i = %d\n", i);
    printf("++i 的值：%d\n", ++i);   /* 先变成 3，再送出 3 */
    printf("现在 i = %d\n", i);
    return 0;
}
```
```output
i++ 的值：1
现在 i = 2
++i 的值：3
现在 i = 3
```

后置 `i++` 的表达式值是**旧值**，自增的动作排在后面完成；前置 `++i` 先自增，表达式值就是**新值**。注意上面每次 `printf` 里只出现一次 `i`——这是安全的。写成 `printf("%d %d\n", i, i++)` 就踩进了未定义行为：同一个表达式里既读 i 又改 i，而参数谁先求值标准没有规定，换台机器结果就可能变。

### 逗号运算符
`(表达式1, 表达式2)` 先计算表达式 1，丢弃其结果，再计算表达式 2，整个表达式的值是表达式 2 的值：

```c run id=comma
#include <stdio.h>

int main(void) {
    int a = 0;
    int x = (a = 3, a + 10);    /* 先 a = 3，再计算 a + 10 */
    printf("x=%d a=%d\n", x, a);
    return 0;
}
```
```output
x=13 a=3
```

它最常见的用途是在 `for` 循环里同时更新两个变量：`for (i = 0, j = n - 1; i < j; i++, j--)`。

注意区分**逗号运算符**和**逗号分隔符**：`int a = 1, b = 2;` 里的逗号、函数调用 `f(a, b)` 里的逗号都只是分隔符，不是逗号运算符。

同样一个 `,`，位置不同，含义可以完全不同：

```c run id=comma-vs-sep
#include <stdio.h>

int main(void) {
    int a = 1, b = 2;
    printf("%d %d\n", a, b);        /* 参数表里的逗号：分隔符，打印两个参数 */
    printf("%d\n", (a = 10, b));    /* 括号里的逗号：运算符，整个表达式的值是 b */
    printf("a=%d b=%d\n", a, b);
    return 0;
}
```
```output
1 2
2
a=10 b=2
```

第二行只打印了一个数 2，不是两个。因为括号里的 `(a = 10, b)` 是**一个**表达式：先执行 `a = 10`（副作用留下了，a 真的变成 10），丢掉这个赋值表达式的值，再计算 `b`，整个表达式的值就是 2。

初学者常以为 `(a, b)` 会把 a 和 b "组合起来"或者"打印两个值"。它什么都不组合，只是"算完前面、扔掉、留下最后一个"。前面那些表达式的**副作用**（赋值、自增、输出）照样会发生，被扔掉的只是它们的值。

### 写法与含义对照
下面这些写法都是一眼看错的常客，拿不准的时候回来对一遍：

| 写法 | 你可能以为 | 实际含义 |
|---|---|---|
| `x *= a + b` | `x = x * a + b` | `x = x * (a + b)`，右边是一个整体 |
| `a = b = 3` | 从左边开始赋值 | 右结合：先 `b = 3`，整个赋值表达式的值是 3，再赋给 a |
| `k = i++` | k 拿到 i 加 1 之后的值 | k 拿到**旧值**，i 自己加了 1 |
| `printf("%d %d", i, i++)` | 参数从左到右依次计算 | 未定义行为，读和改的先后没有规定 |
| `(a, b)` | 把 a 和 b 组合起来 | 只等于 b，a 被算完就丢掉 |

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra assign.c -o assign
```

`-Wall` 可以发现部分"同一变量被无序修改"的问题（`-Wsequence-point` / `-Wunsequenced`）。

## 常见错误

### 以为 x *= a + b 是 x = x * a + b
复合赋值的右边是一个整体：`x *= a + b` 等价于 `x = x * (a + b)`。

### 混淆前置与后置
`k = i++` 中 k 拿到的是旧值；需要新值时写 `k = ++i`。不确定时，拆成两条语句最清楚：`i++; k = i;`。

### 在 printf 的参数里自增
`printf("%d %d\n", i, i++);` 中两个参数的计算顺序没有规定，并且一个读 i、一个改 i，属于未定义行为。

### 把复合赋值的符号和 = 拆开了
`x =- 1;` 不是 `x -= 1`，而是 `x = -1`。C 只看符号有没有挨在一起：`=-` 会被读成"赋值号 `=`"加上"一元负号 `-`"，于是 x 直接变成负 1，而不是减 1。

好消息是编译器其实看出来了，开启 `-Wall` 会给出 `use of unary operator that may be intended as compound assignment (-=)` 这样的警告。坏消息是：不打开警告、或者看到了不当回事，程序就会照常运行，只是结果莫名其妙——这是最难查的一类 bug。写复合赋值时把符号和 `=` 紧挨着写：`x -= 1;`。

## 客观题

### q-s1-assign-comma-1 single
执行 `int a = 2, b; b = (a += 3, a * 2); a *= b - 6;` 之后，a 和 b 的值是：
- [ ] a = 4，b = 10
  > `a *= b - 6` 是 `a = a * (b - 6)`，不是 `a = a * b - 6`。
- [x] a = 20，b = 10
  > 正确。逗号运算符先执行 a += 3（a = 5），再计算 a * 2 = 10 赋给 b；最后 a = 5 * (10 - 6) = 20。
- [ ] a = 44，b = 10
  > 这是按 `a = a * b - 6` 计算的结果（5 × 10 − 6 = 44），复合赋值的右边应当作为整体。
- [ ] a = 20，b = 4
  > 逗号表达式的值是**最后一个**表达式 `a * 2` 的值，不是第一个。
