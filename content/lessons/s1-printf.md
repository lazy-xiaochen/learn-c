## 讲解

### printf 的基本结构
```c
printf("格式字符串", 参数1, 参数2, ...);
```
格式字符串中的普通字符原样输出；以 `%` 开头的**格式说明符**是占位符，依次被后面的参数替换。说明符必须和参数的**类型一一对应**，数量也必须一致。

### 常用格式说明符
| 说明符 | 参数类型 | 示例输出 |
|---|---|---|
| `%d` | `int` | `-42` |
| `%u` | `unsigned int` | `4294967295` |
| `%ld` / `%lld` | `long` / `long long` | `9000000000` |
| `%llu` | `unsigned long long` | |
| `%zu` | `size_t`（sizeof 的结果） | `8` |
| `%f` | `double`（`float` 会自动提升为 double） | `3.140000` |
| `%e` / `%g` | `double`：科学计数法 / 自动选择较短形式 | `3.140000e+00` / `3.14` |
| `%c` | `int`（字符） | `A` |
| `%s` | 字符串 | `hello` |
| `%x` / `%X` | 无符号整数，十六进制小写 / 大写 | `ff` / `FF` |
| `%o` | 无符号整数，八进制 | `377` |
| `%p` | 指针（地址） | `000000AB12CDEF00` |
| `%%` | 输出一个 `%` | `%` |

### 宽度、精度与标志
完整写法是 `%[标志][宽度][.精度]说明符`：

```c run id=width
#include <stdio.h>

int main(void) {
    int n = 42;
    double pi = 3.14159265;
    printf("[%5d]\n", n);       /* 宽度 5，默认右对齐，左边补空格 */
    printf("[%-5d]\n", n);      /* - 标志：左对齐 */
    printf("[%05d]\n", n);      /* 0 标志：左边补 0 */
    printf("[%+d]\n", n);       /* + 标志：正数也显示 + 号 */
    printf("[%.2f]\n", pi);     /* 精度：保留 2 位小数（四舍五入） */
    printf("[%8.3f]\n", pi);    /* 宽度 8、精度 3 */
    printf("[%#x] [%#o]\n", 255, 255);   /* # 标志：加上 0x / 0 前缀 */
    printf("[%*d]\n", 6, n);    /* * 表示宽度由参数给出 */
    return 0;
}
```
```output
[   42]
[42   ]
[00042]
[+42]
[3.14]
[   3.142]
[0xff] [0377]
[    42]
```

宽度是**最小**宽度：内容更长时不会被截断，而是原样输出。

### 转义字符：反斜杠开头的"特殊字符"
字符串里有些字符没法直接打出来或者有特殊含义，用 `\` 加一个字母表示。它们全都是**一个字符**，但写出来是两个字符：

| 写法 | 屏幕上得到 | 说明 |
|---|---|---|
| `\n` | 换到下一行 | 最常用；忘了它，几行输出就会挤在一起 |
| `\t` | 一个制表符 | 粗略对齐用，宽度不固定，不适合精确排版 |
| `\\` | 一个反斜杠 `\` | 单个 `\` 会被当成转义序列的开头 |
| `\"` | 一个双引号 `"` | 字符串本身用双引号包着，里面的引号必须转义 |
| `%%` | 一个百分号 `%` | 这是 printf 的规则，不是 C 的转义 |

```c run id=escape
#include <stdio.h>

int main(void) {
    printf("1. 反斜杠要写两个：\\\n");
    printf("2. 想打印引号：\"你好\"\n");
    printf("3. 想打印百分号：100%%\n");
    return 0;
}
```
```output
1. 反斜杠要写两个：\
2. 想打印引号："你好"
3. 想打印百分号：100%
```

初学者最容易在这里栽跟头的是 **`\n` 只写成了 `n`**：`printf("hello n")` 会老老实实输出字母 n，不会换行。反过来，`\` 出现在路径里也要小心——`"C:\new"` 里的 `\n` 会被解释成换行，写成 `"C:\\new"` 才是你想表达的反斜杠。

### 用宽度把结果排成一张表
宽度和 `-` 标志组合起来，就能让多行输出对齐，这是做题时最常用的一招：

```c run id=align
#include <stdio.h>

int main(void) {
    printf("%-6s|%6s|\n", "item", "qty");
    printf("%-6s|%6d|\n", "apple", 3);
    printf("%-6s|%6d|\n", "banana", 12);
    return 0;
}
```
```output
item  |   qty|
apple |     3|
banana|    12|
```

`%-6s` 表示"至少占 6 格、内容靠左"，`%6d` 表示"至少占 6 格、内容靠右"。注意最后一行 `banana` 正好 6 个字符，把格子撑满了，`|` 就紧紧贴上去——所以想让竖线对齐，得先知道最长的那一项有几格宽。

数字默认右对齐是有道理的：个位对齐以后，一列数字上下看大小一目了然；文字一般用 `-` 左对齐，读起来更自然。

还有一个绕不开的坑：**宽度是按字节算的**。一个汉字在 UTF-8 里占 3 个字节，在屏幕上却只占 2 格，所以中英文混排的表格用 `%8s` 怎么调都对不齐。这不是你算错了，而是 printf 的"宽度"和屏幕上的"格数"根本不是一个概念。

### printf 的返回值
`printf` 返回**实际输出的字节数**（出错时返回负数）。注意是字节数，不是"字符数"：在 UTF-8 编码下一个汉字占 3 个字节。

```c run id=ret
#include <stdio.h>

int main(void) {
    int n = printf("hello\n");
    printf("%d\n", n);              /* "hello\n" 共 6 个字节 */
    int m = printf("你好\n");
    printf("%d\n", m);              /* 两个汉字各 3 字节，加换行共 7 */
    return 0;
}
```
```output
hello
6
你好
7
```

### 说明符与参数类型不匹配
这是 printf 最危险的错误。printf 是**可变参数**函数，编译器无法自动转换参数类型，printf 只会按格式说明符去"解读"内存里的数据：

```c run id=mismatch warnings=allow
#include <stdio.h>

int main(void) {
    printf("%d\n", 4294967295u);   /* 无符号数按有符号解读 */
    printf("%u\n", -1);            /* 有符号数按无符号解读 */
    return 0;
}
```
```output
-1
4294967295
```

更严重的情况（比如用 `%d` 输出 `double`、用 `%s` 输出整数）是**未定义行为**，可能输出乱码，也可能直接崩溃。阶段 5 会专门讨论。

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra fmt.c -o fmt
```

`-Wall` 包含 `-Wformat`，会检查格式字符串与参数是否匹配，例如 `format specifies type 'int' but the argument has type 'double'`。**这类警告几乎一定是 bug。**

## 常见错误

### 用 %d 输出 long long、size_t 或 double
分别应当用 `%lld`、`%zu`、`%f`。

### 参数个数比说明符少
`printf("%d %d\n", a);` 第二个 `%d` 会读取一个不存在的参数，是未定义行为。

### 想输出百分号却只写了一个 %
`printf("完成 100%\n")` 中 `%\n` 不是合法的说明符，应写成 `100%%`。

### 以为 %5d 会把超长的数字截断
宽度是**最小**宽度，内容比它长就原样输出。真想截断只能用精度：`%.3s` 表示"只要前 3 个字符"。

```c run id=truncate
#include <stdio.h>

int main(void) {
    printf("[%5d]\n", 123456);      /* 比宽度长：原样输出，不截断 */
    printf("[%.3s]\n", "banana");   /* 精度：只取前 3 个字符 */
    return 0;
}
```
```output
[123456]
[ban]
```

## 客观题

### q-s1-printf-1 single
执行 `int k = printf("[%4d]", 7); printf("%d", k);` 后，屏幕上的完整输出是：
- [ ] `[7]1`
  > `%4d` 的宽度至少为 4，7 左边会补 3 个空格。
- [x] `[   7]6`
  > 正确。第一个 printf 输出 `[   7]`，共 6 个字符（两个方括号、三个空格、一个 7），返回值 6 被第二个 printf 输出。
- [ ] `[   7]4`
  > 返回值是整个输出的字符数，方括号也算在内。
- [ ] `[7   ]6`
  > 默认右对齐，空格补在左边；左对齐需要 `-` 标志。
