## 讲解

### 指针变量自己也有地址
学指针时我们已经知道：变量存放在内存里，所以每个变量都有地址。**指针也是变量**，它同样占内存、同样有地址。`int *p = &x;` 只是把 `x` 的地址存进了 `p`；而 `p` 自己住在另一块内存里，用 `&p` 就能拿到它的地址。

保存"指针的地址"的变量，就是**二级指针**：

```c
int x = 42;
int *p = &x;        /* p 的类型是 int *，里面存 &x */
int **pp = &p;      /* pp 的类型是 int **，里面存 &p */
```

类型是一层一层套起来的：

| 表达式 | 类型 | 它的值是什么 |
|---|---|---|
| `x` | `int` | 42 |
| `p` | `int *` | `&x`（x 的地址） |
| `*p` | `int` | 42（就是 x） |
| `pp` | `int **` | `&p`（p 的地址） |
| `*pp` | `int *` | `&x`（就是 p 的值） |
| `**pp` | `int` | 42（就是 x） |

`*` 每多一次，就沿着地址链多走一步。所以 `**pp` 和 `x` 是同一个东西，`*pp` 和 `p` 是同一个东西。

```c run id=basic
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;
    int **pp = &p;              /* pp 指向 p */

    printf("x = %d\n", x);
    printf("*p = %d\n", *p);
    printf("*pp == p 吗？%s\n", *pp == p ? "是" : "否");
    printf("**pp = %d\n", **pp);
    return 0;
}
```
```output
x = 42
*p = 42
*pp == p 吗？是
**pp = 42
```

### 为什么需要二级指针：C 的参数永远是值传递
前面学过：想在一个函数里修改调用者的变量，就要把它的地址传进去。这个规律对"指针变量"同样成立：

- 想改调用者的 `int`，函数参数用 `int *`，函数里写 `*p = ...`；
- 想改调用者的 `int *`（也就是让它指向别处），函数参数就要用 `int **`，函数里写 `*pp = ...`。

原因还是值传递：函数收到的 `pp` 只是调用者指针的一个**副本**。在函数里写 `pp = 别的地址;` 改的是这个副本，调用者的指针纹丝不动；只有 `*pp = 别的地址;` 才是"顺着副本找到调用者的那个指针变量，往它里面写"。

```c run id=out-param
#include <stdio.h>

/* 让调用者的指针指向数组中的最大值 */
void point_to_max(int **pp, int *a, int n) {
    int *best = &a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > *best) {
            best = &a[i];
        }
    }
    *pp = best;              /* 写进调用者的指针变量，而不是改形参 */
}

int main(void) {
    int a[5] = {3, 9, 2, 7, 5};
    int *p = NULL;

    point_to_max(&p, a, 5);
    printf("最大值 = %d，下标 = %ld\n", *p, (long)(p - a));
    return 0;
}
```
```output
最大值 = 9，下标 = 1
```

`&p` 的类型正是 `int **`，这就是调用时必须写 `&p` 而不能写 `p` 的原因。函数成功地把"最大值在哪里"这个**位置信息**带回了调用者——这比返回一个下标更通用，因为指针可以直接用来访问元素。

### 反例：只改形参，调用者什么也收不到
把上面函数里的 `*pp = best;` 手滑写成 `pp = &best;`，编译一样通过（类型都是 `int **`），但结果是错的：

```c run id=wrong-param
#include <stdio.h>

/* 错误示范：只改了形参自己 */
void bad(int **pp, int *target) {
    int *local = target;
    pp = &local;        /* 改的是形参 pp，调用者完全感觉不到 */
    printf("函数内部 *pp 指向 %d，看起来成功了\n", **pp);
}

int main(void) {
    int a[3] = {10, 20, 30};
    int *p = &a[2];

    bad(&p, &a[0]);
    printf("p 还指向 a[2] 吗？%s\n", p == &a[2] ? "是" : "否");
    printf("*p = %d\n", *p);
    return 0;
}
```
```output
函数内部 *pp 指向 10，看起来成功了
p 还指向 a[2] 吗？是
*p = 30
```

注意 `bad` 内部的打印是 10：在函数里看，`*pp` 确实指向了 `a[0]`，一切"正常"。但回到 `main`，`p` 仍然指向 `a[2]`——`pp = &local;` 只修改了形参这个副本。这种"函数里对、函数外错"的 bug 极难发现，所以二级指针的赋值一定要检查等号左边有没有 `*`。

更糟的是，`local` 是 `bad` 的局部变量，函数一返回它就不存在了。即使调用者通过某种方式拿到了 `&local`，那也是一个**悬垂指针**。所以写二级指针参数时，一定要盯住：我要改的是 `pp`，还是 `pp` 指向的那个指针？答案永远是后者，所以必须写 `*pp = ...`。

### 二级指针与指针数组
`int *ps[3] = {&x, &y, &z};` 是一个"指针数组"：3 个元素，每个都是 `int *`。数组名在表达式里会退化成"指向首元素的指针"，而首元素本身就是 `int *`，所以退化后的类型是 `int **`。这正是二级指针最常见的来源之一。

```c run id=ptr-array
#include <stdio.h>

int main(void) {
    int x = 10, y = 20, z = 30;
    int *ps[3] = {&x, &y, &z};
    int **pp = ps;              /* 数组名退化成 int ** */

    for (int i = 0; i < 3; i++) {
        printf(i == 0 ? "%d" : " %d", **(pp + i));
    }
    printf("\n");
    return 0;
}
```
```output
10 20 30
```

`pp + i` 前进 `sizeof(int *)` = 8 字节，指向第 i 个"指针元素"；再解引用一次得到那个指针，第二次解引用才拿到真正的 int。后面"指针数组与数组指针"一节会详细展开这个结构。

### 二级指针的内存图
```memory title="int x = 42; int *p = &x; int **pp = &p;（地址为示意，实际每次运行可能不同）"
地址    | 内容   | 名字 | 类型   | 解引用一次得到 | 解引用两次得到
0x1000  | 42     | x    | int    | —              | —
0x2000  | 0x1000 | p    | int *  | 42             | —
0x2008  | 0x2000 | pp   | int ** | 0x1000         | 42
```

看图就能明白解引用的过程：`pp` 里存的是 `0x2000`（p 的地址），所以 `*pp` 读出来是 `0x1000`（p 里存的值）；再解引用一次，沿着 `0x1000` 找到 x，得到 42。

### 什么时候真的需要二级指针
1. **函数要修改调用者的指针**：例如让指针指向查找结果、把链表头指针传进函数做头插/删除（第 4 阶段）。
2. **函数要"返回"一块新分配的内存**：`void create(int **out)` 里写 `*out = malloc(...)`（第 5 阶段）。
3. **遍历指针数组**：`int *rows[10]` 这类结构的数组名退化后就是 `int **`。

反过来说，如果函数**不需要**改调用者的指针，就不要用二级指针。用 `int **` 当参数意味着"我可能会改写你的指针"，是一种很强的承诺。

### 一个必须记住的区分：`int **` 不是二维数组
`int m[3][4];` 的 `m` 退化后是 `int (*)[4]`（指向"4 个 int 的一行"的指针），而 `int **` 是"指向 int 指针的指针"。两者的内存结构完全不同：二维数组是一整块连续内存，`int **` 指向的是一串**分散的指针**。把二维数组传给 `int **` 参数，编译器会直接报 `incompatible pointer types` 错误，根本通不过编译。这一点在下一节"指针数组与数组指针"里会彻底讲清。

## 编译与运行

```bash
gcc -std=c17 -Wall -Wextra multi.c -o multi
./multi
```

本平台用 Clang，命令等价：`clang -std=c17 -Wall -Wextra multi.c -o multi`。

调试二级指针时，`-g` 加上调试器可以逐层查看：先看 `pp` 的值（p 的地址），再看 `*pp` 的值（x 的地址），最后看 `**pp`。也可以临时用 `printf("%p %p %p\n", (void *)&x, (void *)p, (void *)pp);` 打印三个地址来对照内存图——但注意这种输出每次运行都不同，不能写进需要固定输出的程序里。

## 常见错误

### 在函数里写 `pp = ...` 而不是 `*pp = ...`
这是二级指针的头号错误。`pp = 新地址;` 只修改了形参副本，函数返回后调用者的指针一点没变。凡是"通过二级指针带回结果"，赋值号左边必须是 `*pp`。

### 解引用次数不对：把 `*pp` 当成值用
`*pp` 的类型是 `int *`（一个地址），`**pp` 才是 `int`。如果把 `*pp` 直接 `printf("%d", *pp)`，拿到的是地址被当成整数打印，结果毫无意义（`-Wformat` 也会警告）。写之前先问自己：这个表达式还需要再解引用几次才是 `int`？

### 把二维数组直接传给 `int **`
`int m[3][4]; f(m);` 里 `f` 的形参如果写成 `int **`，类型是不兼容的。二维数组的内存是连续的，没有"指针数组"这一层间接。正确写法是 `void f(int (*m)[4], int rows)` 或 `void f(int m[][4], int rows)`。

### 让二级指针指向局部变量
```c
void f(int **out) {
    int local = 5;
    *out = &local;      /* 函数返回后 local 就没了 */
}
```
函数返回后 `local` 所在的那块栈内存已经失效，`*out` 成了悬垂指针，再访问就是未定义行为。要么让指针指向调用者提供的对象，要么用动态内存（第 5 阶段）。

### 忘记给二级指针本身分配目标
```c
int **pp;               /* 野指针：pp 里是垃圾值 */
*pp = &x;               /* 往一个未知地址写，直接崩溃 */
```
`pp` 必须先指向一个真实存在的 `int *` 变量（通常就是 `pp = &p;`），才能对它解引用。

## 客观题

### q-s2-multi-pointer-1 single
```c
int x = 5;
int *p = &x;
int **pp = &p;
```
下面哪个表达式的值等于 5？

- [x] `**pp`
  > 正确。`pp` 指向 `p`，`*pp` 就是 `p`（类型 `int *`，值是 `&x`）；再解引用一次 `**pp` 才到达 `x`，得到 5。
- [ ] `*pp`
  > `*pp` 的值就是 `p` 的值，也就是 `&x`——一个地址，不是 5。它的类型是 `int *`。
- [ ] `&pp`
  > 这是 `pp` 变量自己的地址，类型是 `int ***`，和 5 没有任何关系。
- [ ] `*(&p)`
  > `&p` 是 `p` 的地址，再解引用一次就回到 `p` 本身（类型 `int *`，值是 `&x`），仍然不是 5。它等价于 `p`。
