## 讲解

### 为什么 scanf 要写 &
`printf("%d", x)` 只需要知道 x 的**值**；而 `scanf` 要把读到的数据**存进** x，所以它需要知道 x 在内存里的**位置**。`&x` 就是"x 的地址"（第 2 阶段学指针时会彻底弄清楚）。忘记写 `&` 是初学者最常见、后果也最严重的错误之一。

### 格式说明符：与 printf 不完全对称
| 变量类型 | scanf | printf |
|---|---|---|
| `int` | `%d` | `%d` |
| `unsigned int` | `%u` | `%u` |
| `long long` | `%lld` | `%lld` |
| `float` | `%f` | `%f` |
| `double` | **`%lf`** | `%f`（`%lf` 也可以） |
| `char` | `%c` | `%c` |

`double` 是最容易出错的：`printf` 的参数中 float 会被自动提升为 double，所以 `%f` 两者通用；但 `scanf` 拿到的是**地址**，必须准确告诉它这块内存是 4 字节的 float（`%f`）还是 8 字节的 double（`%lf`）。

### 空白与字面字符
- `%d`、`%lf`、`%s` 等会**自动跳过前面的空白**（空格、制表符、换行），所以数据分几行输入都可以；
- 格式串里的一个空格匹配**任意多个**空白（包括零个）；
- 格式串里的其他字符必须在输入中**原样出现**，否则匹配失败、scanf 停止。

```c run id=literal stdin="2024-03-09"
#include <stdio.h>

int main(void) {
    int y, m, d;
    int n = scanf("%d-%d-%d", &y, &m, &d);   /* 输入中必须有两个 - */
    printf("读到 %d 项：%d 年 %d 月 %d 日\n", n, y, m, d);
    return 0;
}
```
```output
读到 3 项：2024 年 3 月 9 日
```

### 数据可以分几行输入
格式串里虽然只写了一个空格，但 `%d` 在开始读之前会先跳过**任意多个空白**（空格、制表符、换行都算）。所以数据是写成一行还是写成三行，结果完全一样：

```c run id=multiline stdin="1\n2\n3\n"
#include <stdio.h>

int main(void) {
    int a, b, c;
    int n = scanf("%d %d %d", &a, &b, &c);
    printf("读到 %d 项：%d + %d + %d = %d\n", n, a, b, c, a + b + c);
    return 0;
}
```
```output
读到 3 项：1 + 2 + 3 = 6
```

初学者常以为格式串里的空格必须和输入里的空格一一对应，于是盯着输入数空白、担心换行会不会读错。不用：空格在这里的意思是"**跳过**空白"，不是"匹配一个空白"。输入写成 `1 2 3`、`1⏎2⏎3`、甚至前面带几个空格，读到的都是同样三个数。

反过来，格式串里的**逗号、冒号、减号**这类字符是必须真的出现的——它们不是空白，不能被跳过。这一正一反正是 scanf 格式串的全部规则。

### 返回值：成功赋值的项数
`scanf` 的返回值告诉你实际读到了几个数据，这是判断输入是否合法的**唯一可靠办法**：

| 情况 | 返回值 |
|---|---|
| 全部成功 | 说明符的个数 |
| 中途遇到不匹配的内容 | 已经成功的个数（可能是 0） |
| 还没读到任何数据就遇到输入结束 | `EOF`（一个负数，通常是 -1） |

匹配失败时，**没有被赋值的变量保持原来的值**；如果它们没有初始化，就是不确定的垃圾值。

```c run id=retval stdin="12 abc"
#include <stdio.h>

int main(void) {
    int a = -1, b = -1;
    int n = scanf("%d %d", &a, &b);
    printf("返回 %d，a = %d，b = %d\n", n, a, b);   /* b 没有被赋值 */
    return 0;
}
```
```output
返回 1，a = 12，b = -1
```

### 把返回值用起来：先检查，再使用
既然返回值能告诉我们读到了几项，就应该每次都检查。这是"健壮的输入"的标准写法：

```c run id=check stdin="abc"
#include <stdio.h>

int main(void) {
    int a = 0, b = 0;
    int n = scanf("%d %d", &a, &b);
    if (n != 2) {
        printf("输入不合法：只读到了 %d 项\n", n);
        return 0;            /* 输入不合法的处理，不是程序出错，所以仍然返回 0 */
    }
    printf("和是 %d\n", a + b);
    return 0;
}
```
```output
输入不合法：只读到了 0 项
```

输入 `abc` 时 `%d` 一项也读不到，返回 0，a、b 保持初始化时的 0。假如不检查返回值，程序会拿两个没被赋值的变量去相加，算出来的东西毫无意义——而且它不会报错，只会安静地给出一个错误答案。

顺带一个习惯：**声明时就把变量初始化**（`int a = 0, b = 0;`）。这样即使后面读取失败，程序的行为也是可预期的、可以调试的。

### 跳过不需要的数据：%*d
在 `%` 和说明符之间加 `*`，表示"读入并丢弃"，不需要对应的参数，也不计入返回值：

```c run id=skip stdin="10 20 30"
#include <stdio.h>

int main(void) {
    int first, third;
    int n = scanf("%d %*d %d", &first, &third);
    printf("%d %d %d\n", n, first, third);
    return 0;
}
```
```output
2 10 30
```

### scanf 的坑，一张表记住
| 想做的事 | 正确写法 | 常见错法 | 后果 |
|---|---|---|---|
| 读一个 `int` | `scanf("%d", &x)` | `scanf("%d", x)` | 把变量的值当地址，向随机位置写入，通常直接崩溃 |
| 读一个 `double` | `scanf("%lf", &d)` | `scanf("%f", &d)` | 只写入 4 字节，d 的值是错的 |
| 读一个字符并跳过前面的空白 | `scanf(" %c", &c)` | `scanf("%c", &c)` | 读到上一行残留的换行符 |
| 读 3 个数 | `if (scanf("%d %d %d", &a, &b, &c) != 3)` | 不检查返回值 | 后续计算全用未赋值的变量 |
| 读 `1,2` 这种带逗号的输入 | `scanf("%d,%d", &a, &b)` | `scanf("%d %d", &a, &b)` | 第二个数读不到，返回值是 1 |
| 格式串末尾 | 什么都不加 | `scanf("%d\n", &x)` | 读完数字还在等非空白字符，程序像卡住了 |

## 常见错误

### 漏写 &
`scanf("%d", x)` 把 x 的**值**当作地址，向一个随机位置写入数据，通常会让程序崩溃。

### 用 %f 读 double
`double d; scanf("%f", &d);` 只写入了 d 的 4 个字节，d 的值是错误的。必须用 `%lf`。

### 格式串末尾加了 \n
`scanf("%d\n", &x)` 中的 `\n` 是空白，它会匹配"任意多个空白"——于是 scanf 在读完数字后会**一直等待**，直到你输入一个非空白字符为止。格式串末尾不要加 `\n` 或空格。

### 不检查返回值
输入不合法时，后面的计算全都基于未赋值的变量。始终检查：`if (scanf("%d %d", &a, &b) != 2) { 处理错误 }`。

### 在格式串里写提示文字
printf 里可以写"请输入两个数："这样的提示，scanf 的格式串里**绝对不行**。格式串里的普通字符必须在输入中原样出现，否则匹配立刻失败：

```c run id=prompt-in-format stdin="5\n"
#include <stdio.h>

int main(void) {
    int x = -1;
    int n = scanf("请输入一个整数：%d", &x);   /* 输入里不可能有这几个汉字 */
    printf("返回 %d，x = %d\n", n, x);
    return 0;
}
```
```output
返回 0，x = -1
```

输入 `5` 的第一个字节是字符 `5`，而格式串期待的是汉字"请"的第一个字节，两者对不上，`%d` 连试都没试就结束了，返回 0。提示文字要用 `printf` 单独输出，`scanf` 的格式串里只留 `%d` 这样的说明符和必要的分隔字符。

## 客观题

### q-s1-scanf-1 single
输入为 `3 4` 时，执行 `int a = 0, b = 0; int n = scanf("%d,%d", &a, &b);` 后，n、a、b 的值分别是：
- [ ] 2、3、4
  > 格式串要求两个数之间有一个逗号，而输入中是空格，第二个 %d 之前的 `,` 匹配失败。
- [x] 1、3、0
  > 正确。成功读入 a = 3 后，scanf 期待一个逗号却遇到了空格，于是停止，返回成功的项数 1；b 保持原值 0。
- [ ] 0、0、0
  > 第一个 %d 已经成功读到了 3。
- [ ] -1（EOF）、3、0
  > EOF 只在"还没读到任何数据就遇到输入结束"时返回，这里已经成功读了一项。
