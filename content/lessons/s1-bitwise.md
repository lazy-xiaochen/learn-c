## 讲解

### 用二进制看整数
整数在内存里是一串二进制位。以 8 位为例：

| 十进制 | 二进制 | 十六进制 |
|---|---|---|
| 5 | `0000 0101` | `0x05` |
| 12 | `0000 1100` | `0x0C` |
| 255 | `1111 1111` | `0xFF` |

最右边的是第 0 位（最低位），往左依次是第 1、2、3……位。第 k 位为 1 时贡献 2ᵏ。十六进制的一位正好对应四个二进制位，所以写位运算时常用十六进制（`printf` 用 `%X` 或 `%x` 输出）。

### 六个位运算符
| 运算符 | 名称 | 规则（逐位） | 示例（8 位） |
|---|---|---|---|
| `&` | 按位与 | 两位都是 1 才得 1 | `1100 & 0101 = 0100` |
| `\|` | 按位或 | 有一位是 1 就得 1 | `1100 \| 0101 = 1101` |
| `^` | 按位异或 | 两位不同得 1 | `1100 ^ 0101 = 1001` |
| `~` | 按位取反 | 0 变 1，1 变 0 | `~0000 1100 = 1111 0011` |
| `<<` | 左移 | 整体左移，右边补 0；左移 k 位相当于乘 2ᵏ | `0000 0101 << 2 = 0001 0100` |
| `>>` | 右移 | 整体右移；右移 k 位相当于除以 2ᵏ | `0001 0100 >> 2 = 0000 0101` |

```c run id=ops
#include <stdio.h>

int main(void) {
    unsigned int a = 12, b = 5;      /* 1100 和 0101 */
    printf("%u %u %u\n", a & b, a | b, a ^ b);
    printf("%u %u\n", a << 2, a >> 2);
    printf("%X\n", ~0u);             /* 32 个 1 */
    return 0;
}
```
```output
4 13 9
48 3
FFFFFFFF
```

### 对某一位进行操作
设 `mask = 1u << k`（只有第 k 位是 1）：

| 目的 | 写法 | 原理 |
|---|---|---|
| 把第 k 位置 1 | `x \| mask` | 与 1 做或，一定得 1；其他位与 0 做或，不变 |
| 把第 k 位清 0 | `x & ~mask` | `~mask` 只有第 k 位是 0 |
| 把第 k 位翻转 | `x ^ mask` | 与 1 异或会翻转，与 0 异或不变 |
| 取出第 k 位 | `(x >> k) & 1u` | 把第 k 位移到最低位，再只保留最低位 |

```c run id=bit-k stdin="10 1"
#include <stdio.h>

int main(void) {
    unsigned int x, k;
    if (scanf("%u %u", &x, &k) != 2 || k > 31) return 1;
    unsigned int mask = 1u << k;       /* 用 1u：无符号的 1 */
    printf("置1: %u\n", x | mask);
    printf("清0: %u\n", x & ~mask);
    printf("翻转: %u\n", x ^ mask);
    printf("第%u位: %u\n", k, (x >> k) & 1u);
    return 0;
}
```
```output
置1: 10
清0: 8
翻转: 8
第1位: 1
```

### 移位的规则与陷阱
- 移位的位数必须在 0 到"类型位数 − 1"之间：`1u << 32` 对 32 位的 `unsigned int` 是**未定义行为**；
- 对**有符号**数左移，如果结果超出范围（包括移进符号位），是未定义行为：`1 << 31` 就是（int 为 32 位时）；
- 对负数右移，结果由实现决定（常见实现是补符号位）。

结论：**做位运算时一律使用无符号类型**，常量写成 `1u`、`1ull`。

```c run id=shift-ub expect=UB stdin="31"
#include <stdio.h>

int main(void) {
    int k;
    if (scanf("%d", &k) != 1) return 1;
    int mask = 1 << k;          /* k = 31 时：有符号左移溢出 */
    printf("%d\n", mask);
    return 0;
}
```

### 左移右移就是乘除 2 的幂
左移 k 位等于乘 2ᵏ，右移 k 位等于除以 2ᵏ 并丢掉余数（对正整数）：

```c run id=shift-mul stdin="9"
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 1;
    printf("左移 1 位：%d\n", n << 1);     /* 9 × 2 = 18 */
    printf("右移 1 位：%d\n", n >> 1);     /* 9 ÷ 2 = 4，余数 1 被丢掉 */
    printf("左移 3 位：%d\n", n << 3);     /* 9 × 8 = 72 */
    return 0;
}
```
```output
左移 1 位：18
右移 1 位：4
左移 3 位：72
```

`9 >> 1` 得到 4 而不是 4.5，这和整数除法的截断是一致的——右移本来就只是"除以 2 的幂"的另一种写法。

有些资料把移位说成"性能技巧"：`n << 3` 比 `n * 8` 快。这在今天不成立，编译器会自动把 `n * 8` 优化成移位。反过来，手写移位还要自己承担"有符号数左移溢出"的风险。所以**算术就该用算术运算符**，位运算留给它真正擅长的场合：掩码、标志位、逐位打包。

### 一个常用技巧：x & (x − 1)
`x - 1` 会把 x 最低位的那个 1 变成 0，并把它右边的 0 都变成 1。所以 `x & (x - 1)` 正好**去掉 x 最低位的 1**。由此：x 是 2 的幂（只有一位是 1），当且仅当 `x != 0 && (x & (x - 1)) == 0`。

```c run id=pow2 stdin="64"
#include <stdio.h>

int main(void) {
    unsigned int x;
    if (scanf("%u", &x) != 1) return 1;
    printf("%u 是 2 的幂：%d\n", x, x != 0 && (x & (x - 1)) == 0);
    return 0;
}
```
```output
64 是 2 的幂：1
```

这条判断拆成两半看：`x != 0` 排除 0（0 不是 2 的幂，而 `0 & -1` 恰好也是 0，不加这个条件会误判）；`(x & (x - 1)) == 0` 检查"去掉最低位的 1 之后是不是空了"。

括号千万不能省：`&` 的优先级比 `==` **低**，写成 `x & (x - 1) == 0` 会被解释成 `x & ((x - 1) == 0)`，结果是 0 或 1，和你想判断的东西完全无关。把输入换成 63（二进制 111111）再试一次，输出就变成 0。

### 位运算易错点清单
| 写法 | 你可能以为 | 实际结果 | 原因 |
|---|---|---|---|
| `~0` | 得到 0 | 在本平台是 -1 | 32 个 1 按有符号数解释就是 -1 |
| `!5` | 把 5 的二进制取反 | 得到 0 | `!` 是逻辑非，"非 0"一律变 0 |
| `x & 1 == 0` | 判断 x 的奇偶 | 恒为 0 | `==` 比 `&` 优先级高，实际是 `x & 0` |
| `1 << 31` | 得到 2147483648 | 未定义行为 | 有符号数左移溢出，符号位被改写 |
| `-1 >> 1` | 得到 0 | 通常是 -1 | 负数右移空出来的高位补什么由实现决定 |
| `x << 1` 比 `x * 2` 快 | 手写移位能提速 | 一样快 | 编译器会自动做这个替换 |

## 常见错误

### 用有符号的 1 做掩码
`1 << 31` 是未定义行为，`1 << 35` 也是。写 `1u << k`（32 位）或 `1ull << k`（64 位）。

### 把位运算和逻辑运算混淆
`!` 是逻辑非（非 0 变 0，0 变 1），`~` 才是按位取反：`x & !mask` 通常得到 0，而 `x & ~mask` 才是清除某一位。`&&` 与 `&`、`||` 与 `|` 也是完全不同的运算。

### 忘记位运算的优先级很低
`x & 1 == 0` 实际是 `x & (1 == 0)`，即 `x & 0`，永远为 0。涉及 `&`、`|`、`^` 的比较要加括号：`(x & 1) == 0`。下一节会专门讲。

### 移位位数是个变量时忘了检查范围
移位的位数必须在 0 到"类型位数 − 1"之间。位数来自输入时，一定要先检查：

```c run id=shift-range expect=UB stdin="40"
#include <stdio.h>

int main(void) {
    unsigned int k;
    if (scanf("%u", &k) != 1) return 1;
    unsigned int mask = 1u << k;      /* k = 40：对 32 位类型来说位数越界 */
    printf("%u\n", mask);
    return 0;
}
```

注意这里已经用了无符号的 `1u`，照样越界：无符号只解决了"符号位"的问题，解决不了"移位数太大"。正确做法是先判断 `k < 32`（严谨一点写 `k < sizeof(unsigned int) * 8`），不满足就直接报错退出。

## 客观题

### q-s1-bitwise-1 single
设 `unsigned int x = 0x2C;`（二进制 0010 1100），下面哪个表达式的值是 `0x28`？
- [ ] `x | (1u << 2)`
  > 第 2 位本来就是 1，置 1 后不变，结果仍是 0x2C。
- [x] `x & ~(1u << 2)`
  > 正确。清除第 2 位：0010 1100 → 0010 1000，即 0x28。
- [ ] `x >> 2`
  > 右移两位得到 0000 1011，即 0x0B。
- [ ] `x & !(1u << 2)`
  > `!(1u << 2)` 是逻辑非，`1u << 2` 非 0，所以 `!` 的结果是 0，x & 0 = 0。
